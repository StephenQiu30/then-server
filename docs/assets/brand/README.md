# 衣序品牌资源

更新：2026-10-13。状态：Figma 设计与导出资源已接入 Web 导航、认证页与图标；iOS 的 BrandMark 与 AppIcon 也已迁移。配色、净空和组件边界以 [共享 DESIGN](../../../DESIGN.md) 为准。

| 文件 | 用法 |
| --- | --- |
| `wearlog-symbol-blue.svg` | 蓝色透明图形；导航推荐 32px，最小 16px |
| `wearlog-symbol-ink.svg` | 墨色单色图形 |
| `wearlog-symbol-white.svg` | 白色反白图形，放在蓝色或深色背景 |
| `wearlog-wordmark.svg` | 蓝色 W 图形与 WEARLOG / 衣序组合标志，文字已转轮廓 |
| `wearlog-app-icon.svg` | 不透明方形应用图标，平台负责外形裁切 |
| 同名 PNG | 蓝色图形 256×256、组合标志为 Figma 原尺寸导出、应用图标 256×256 预览 |
| `exports.json` | 设计节点与色值清单 |

SVG 为矢量源，可按目标平台尺寸导出。蓝白是品牌点缀：不能将 Logo 的蓝色用于按钮、选中、导航、表单或成功状态。保留 Vercel/shadcn 中性组件。
