# 动态预览需求

## 状态与上位需求

- 状态：`approved_with_gates`，需求边界已批准，2026-08-30；生产启用受门禁。
- 上位需求：[`10-OOTD产品需求.md`](10-OOTD产品需求.md)。本文细化其中“2.5D 动态预览只有在静态试穿已通过质量、成本、隐私和延迟门槛后条件启用”的要求。
- 前置能力：[`14-AI虚拟试穿需求.md`](14-AI虚拟试穿需求.md) 已在目标地区生产开放，且用户已主动保留一张通过质量门的静态试穿结果；动态任务继承 [`17-云端生成与任务管理需求.md`](17-云端生成与任务管理需求.md) 的共用云任务契约，再叠加本文的动态专属质量、交互、性能和删除规则。
- 产品定义：动态预览是由 AI 生成视角组成、可左右拖动浏览的 2.5D 视觉效果。它不是三维人体、真实 360° 重建、可信背面、数字孪生或服装物理模拟。
- 启用语义：本文批准“动态实验”发布层级的产品体验与表示边界，不批准任何视频供应商处理真实用户素材。动态 POC、供应商许可与地域、训练禁用、删除、质量、成本、生成延迟、最低设备播放性能、无障碍和独立 feature flag 全部通过后，才可向对应地区和版本开放。
- 关闭语义：门禁未通过、开关关闭或运行中触发止损条件时，始终回退用户已保留的静态试穿图；推荐、保存、穿搭计划和反馈不受影响。

## 背景与问题

静态试穿可以帮助用户判断正面整体效果，但用户可能希望用更自然、可控制的方式观察侧面和模型推测出的其他视角。真实 3D 人体和服装需要多视角采集、服装建模和物理模拟，无法在首版对真实性、成本和隐私作出可靠承诺；普通短视频又不能提供用户拖到任意生成视图的直接操控感。

因此首个候选采用 2.5D 动态预览：以一张用户已接受的静态试穿结果为来源，后台生成有限视角素材，用户左右拖动查看。它应提供愉悦但诚实的视觉增强，而不能让用户误以为看到了真实背面、真实角度或尺码证据。

## 目标用户

- 已主动使用并保留静态 AI 试穿结果，希望进一步观察整体轮廓和不同生成视图的成年用户。
- 愿意在看到本次图片转动态处理方、地域、用途、保留期和删除方式后再次明确同意的用户。
- 能接受生成视角存在推测，但希望交互流畅、随时可回到静态图的用户。
- 开启“减少动态效果”、使用 VoiceOver、网络较弱或设备资源受限的用户，也必须能使用静态替代路径完成任务。

## 产品目标

1. 在静态试穿已经可用的基础上，为用户提供主动触发、可拖动、可停止的 2.5D 动态视觉体验。
2. 静态图始终先出现，动态生成、资源加载或播放失败不产生空白，不阻断选定与保存。
3. 清楚说明侧面和背面属于 AI 推测，不显示未经验证的真实角度、尺寸或几何信息。
4. 用户可以在原始单品、静态试穿和动态预览之间核对，并能报告时序或视角异常。
5. 在最低支持设备、弱网、内存压力和“减少动态效果”条件下提供稳定、无障碍的降级体验。
6. 只有动态 POC 证明值得继续评估，且生产候选链路的增量用户价值、隐私、成本、延迟、质量和性能门禁分别获批后，才按地区进入小流量真实用户实验。

## 非目标

- 不生成人体 Mesh、骨骼、材质、服装模型或物理布料。
- 不提供真实 360°、真实背面、角度刻度、量体、尺码、垂坠或商品细节证明。
- 不提供实时相机 AR、自由视点、用户可控制姿态、服装交互或视频级虚拟试穿。
- 不在推荐结果、静态试穿成功、页面曝光、预取或后台批处理时自动生成。
- 不为三套推荐批量生成动态结果，不把动态生成设为保存穿搭的前置条件。
- 首版不自动播放、不长时间循环旋转，也不以运动吸引用户延长停留。
- 不要求通知、相册写入、运动或定位权限。
- 不把生成、观看、拖动、停留、保留或其他媒体操作当作实际穿着或偏好证据。
- 不长期保留仅用于生成预览的中间视频；首发不提供动态结果下载、导出、系统分享、社交分享或公开链接。

## 功能范围

### 生产候选体验

- 只有用户已保留且仍有效的静态试穿结果显示“生成动态预览”入口。
- 用户点击后看到 2.5D 说明以及本次实际动态处理方、地域、输入、最长保留期和删除方式，并可拒绝。
- 动态生成时静态试穿图保持可见；用户可以继续选定、保存、退出或取消。
- 达到可交互质量后，产品用一次性提示说明“左右拖动查看 AI 动态预览”。
- 横向拖动只切换模型生成的离散视图；竖向滚动仍用于浏览页面，避免手势冲突。
- 提供“原始单品 / 静态试穿 / 动态预览”切换，不显示“正面 0°”“背面 180°”等真实角度标签。
- 用户可以回到静态图、保留动态结果、报告身份/衣物/肢体/闪烁问题或删除；保留只改变媒体生命周期，不自动成为推荐偏好。
- 开启系统“减少动态效果”时默认静态，不自动播放或使用惯性动画，并提供明确的上一视图、下一视图操作。
- 网络、资源或内容质量不足时自动回退最近可用静态图，不能出现白帧、随机跳人或不可取消的等待。

### POC 范围

- 只使用至少 100 组取得明确授权、已通过静态试穿质量门的样本，不直接使用未同意的生产图片。
- 使用相同静态输入对候选动态供应商进行比选，覆盖不同肤色、体型、发型、姿态、服装轮廓、图案、Logo、手臂与头发遮挡。
- 分别记录身份与衣物跨视图稳定性、肢体完整性、闪烁、额外人物、不合理裸露、错误背面、有效结果率、生成 p50/p95、单次成本、地域、保留和删除能力。
- 在最低支持 iPhone、目标网络、弱网、低电量、内存压力、磁盘不足、VoiceOver 和“减少动态效果”环境中验证播放和降级。
- 大陆和海外 POC 分开审批；海外质量基准不能成为大陆生产自动回退。

## 核心用户故事

- 作为用户，我可以先看到静态试穿，再决定动态视图是否值得额外处理我的照片。
- 作为用户，我可以知道动态处理可能使用不同供应商，并对本次处理单独同意或拒绝。
- 作为用户，我可以在生成过程中继续选定和保存穿搭，不必等待动态结果。
- 作为用户，我可以离开页面，回来后继续查看生成状态或结果。
- 作为用户，我可以左右拖动人物查看 AI 生成视图，同时随时切回静态试穿和衣物原图核对。
- 作为用户，我不会看到把模型推测包装成真实 3D、真实背面或准确角度的文案。
- 作为开启“减少动态效果”或使用 VoiceOver 的用户，我可以不用连续动画，通过上一/下一视图完成相同浏览任务。
- 作为网络或设备资源受限的用户，我会看到稳定静态图，而不是白屏、闪屏或崩溃。
- 作为用户，我可以报告人物、衣物、肢体、闪烁或错误背面，并删除整个动态结果。
- 作为用户，我删除来源静态图、人物或衣物后，不会在缓存或重新打开 App 时再次看到旧动态素材。

## 业务规则

1. **`MOTION-RULE-001`** 动态预览只能派生自用户主动保留、通过质量门且仍有效的静态试穿结果；任一条件失效时入口关闭并清理现有派生结果。
2. **`MOTION-RULE-002`** 每次生成必须由用户明确点击触发；静态试穿完成、保存穿搭、页面曝光、滑动浏览和历史复用均不得自动创建动态任务。
3. **`MOTION-RULE-003`** 动态处理与静态试穿是不同目的，无论是否使用相同处理方都必须取得本次独立同意；实际处理方、地域或保留策略有任何不同还必须逐项重新披露，不能用静态同意或模糊总同意替代。
4. **`MOTION-RULE-004`** 用户拒绝动态处理后，静态试穿、推荐、选定、保存和反馈必须保持完整。
5. **`MOTION-RULE-005`** 当前地区没有合规动态供应商时关闭入口，不得自动跨境或换用未披露供应商。
6. **`MOTION-RULE-006`** 生产人物素材和动态结果固定不得用于训练、微调或供应商产品改进。
7. **`MOTION-RULE-007`** 静态图始终是第一帧和最终降级结果；动态可用不能成为保存、计划或实际穿着确认的前置条件。
8. **`MOTION-RULE-008`** 生成视图均为 AI 推测。产品不得显示真实角度刻度，不得使用“360° 扫描”“真实背面”“3D 数字孪生”等表述。
9. **`MOTION-RULE-009`** 首版不自动播放。拖动结束后不能持续旋转；“减少动态效果”开启时不出现自动、惯性或循环动画。
10. **`MOTION-RULE-010`** 动态结果不得改变静态试穿、穿搭组成、衣物属性、推荐依据、穿搭计划或实际穿着事实。
11. **`MOTION-RULE-011`** 只有完整、连续且通过身份、衣物、肢体、时序和内容安全门的结果才能开放拖动；缺失或被篡改时回退静态图。
12. **`MOTION-RULE-012`** 用户取消后立即停止进入新的处理阶段并回到静态图；外部处理尚未停止时应显示“正在停止并清理”，不能冒充已经删除。
13. **`MOTION-RULE-013`** 删除动态结果应覆盖生成中间物、所有视图素材、封面、设备缓存、后台下载和供应商副本；删除完成前不再允许读取。
14. **`MOTION-RULE-014`** 删除来源静态试穿、人物、衣物、关联穿搭或账号时，相关动态结果自动纳入删除范围。
15. **`MOTION-RULE-015`** 动态预览的生成、观看、拖动、停留、保留、删除、重试和举报都不作为实际穿着或穿搭偏好证据。只有用户在与媒体保留分离的反馈动作中明确提交、且之后可撤回的结构化反馈，才可进入推荐学习。
16. **`MOTION-RULE-016`** 静态与动态共用 PRD 17 的任务身份、幂等、状态、取消、迟到结果、配额和删除契约；本文只增加动态输入前置、质量、播放、设备性能和派生清理要求，不得建立第二套云任务语义。

## 用户可见状态与失败恢复

| 状态 | 用户看到 | 可恢复动作 |
| --- | --- | --- |
| 功能未启用 | 已保留的静态试穿，不出现失效动态入口 | 继续选定、保存或反馈。 |
| 静态前置不足 | 说明需先生成并保留合格静态预览 | 返回静态试穿或继续用拼图。 |
| 等待同意 | 2.5D 限制、实际处理方、地域、保留期和删除方式 | 同意后继续；拒绝则留在静态图。 |
| 排队或生成中 | 静态图和“正在生成动态预览”的真实阶段 | 继续浏览、保存、离开或取消。 |
| 部分素材加载 | 静态图或稳定封面，不提前开放不完整拖动 | 等待可交互或继续使用静态图。 |
| 可交互 | AI 标识、一次性拖动提示和三种视图切换 | 拖动、上一/下一、回静态、报告或删除。 |
| 减少动态效果 | 默认静态图，无自动播放和惯性 | 用户主动使用上一/下一视图。 |
| 网络中断 | 已加载视图继续可用；缺失时保持最近稳定图或静态图 | 联网后继续加载，不从头重复生成。 |
| 设备资源不足 | 自动停止动态加载并显示静态图 | 稍后重试；页面和 App 保持可操作。 |
| 动态生成或质量失败 | 不展示问题视频或闪烁视图，说明静态结果仍可用 | 稍后重试、报告或继续保存。 |
| 当前地区不可用 | “当前地区暂不支持动态预览” | 保留静态试穿，不跨境回退。 |
| 正在取消 | 立即回到静态图，显示外部处理和清理状态 | 等待完成或继续其他流程。 |
| 来源已删除或失效 | 动态预览立即不可读 | 使用仍合法存在的单品拼图或文字记录。 |
| 正在删除 | 动态结果从页面消失，显示处理状态 | 等待完成；失败可重试并提供支持入口。 |

动态预览任何失败都不得更改静态结果、选中穿搭、计划、实际穿着和反馈。

## 成功指标及防误导指标

### 成功指标

- 符合资格且看到入口的用户中，主动发起动态预览的比例。
- 用户同意后获得可交互结果的比例，以及生成、质量和加载降级率。
- 动态生成各阶段 p50/p95、取消率和等待放弃率。
- 首次进入动态页面到可交互的 p50/p95，以及拖动反馈延迟、流畅度、内存与崩溃指标。
- 动态可用后发生有效拖动、切回静态核对、保留和异常反馈的比例。
- 身份、衣物、肢体、闪烁、错位、错误背面和内容安全拒绝率及漏放举报率。
- 单次动态任务、单个可交互结果的成本和无效重复任务阻止率。
- 删除按时完成率、设备缓存清理失败率、中间视频超期数和资产复活事件数。
- 开启“减少动态效果”或 VoiceOver 的用户完成查看、返回和删除任务的比例。

### 防误导指标

- 观看、拖动、停留、循环浏览、保留、删除、重试和举报不得计为实际穿着、搭配成功或穿搭偏好；首发没有下载、导出或分享转化口径。
- 不以总帧数、视频时长、停留时长或自动播放次数作为核心产品成功指标。
- 不得通过默认生成、自动播放、制造入口红点或阻断静态保存来提高触发率。
- 不得把“看起来像 3D”作为真实性指标；研究与看板必须记录用户是否误认为真实背面或尺码能力。
- 质量看板必须分别显示身份变化、衣物突变、肢体异常、时序闪烁和错误背面，不能只报告播放成功。
- 性能指标不能靠降低无障碍、忽略“减少动态效果”或展示未过质量门素材来达成。

## 依赖与风险

### 依赖

- 静态 AI 试穿在目标地区已经通过独立生产门禁，并能提供用户已保留的稳定来源结果。
- 动态供应商及其模型、子处理方、许可证、处理地域、训练禁用、保留、取消和删除能力完成准入。
- 授权动态 POC 数据集、人工评测规范、内容安全与异常举报流程。
- 可恢复的后台生成、受控媒体生命周期和来源删除后的完整派生清理能力。
- 最低支持设备的手势、缓存、内存、弱网、VoiceOver 和“减少动态效果”体验验收。
- 已批准的单次成本、月度预算、并发配额、生成 p95 和设备性能预算。

### 风险

- 模型在侧面或背面改变人物身份、肤色、体型、发型、衣物图案、Logo 和轮廓。
- 生成额外人物、不合理裸露、肢体变形、画面闪烁、人物跳位或错误背面。
- 用户把有限生成视图误认为真实 3D、完整背面或商品事实。
- 动态供应商与静态供应商不同，扩大跨境、子处理方、保留和删除面。
- 生成和后处理成本高、等待长，而增量决策价值有限。
- 帧资源造成弱网加载、磁盘与内存压力、白帧、卡顿或崩溃。
- 来源已删除但设备缓存、迟到结果或后台下载使动态素材再次出现。

## 发布门禁

动态预览只有同时满足以下条件才能从内部实验进入受控的真实用户动态实验：

### 前置产品门槛

- 静态 AI 试穿已在目标地区达到其正式生产门槛，且动态入口只出现在用户主动保留的合格静态结果上。
- 动态生成关闭、失败、取消、离线或删除时，静态试穿、推荐、选定、保存和反馈均可完整完成。
- 2.5D、AI 推测、非真实角度与非尺码说明通过用户理解测试；测试人员不会把界面理解为真实 3D 或真实背面。

### POC、供应商与质量门槛

- 至少 100 组明确授权的合格静态样本完成动态 POC，覆盖代表性人物、服装、遮挡和光照组合。
- 每个候选供应商使用同一输入集，完整报告身份、衣物、肢体、闪烁、错位、错误背面、有效结果率、生成 p50/p95 和单次成本。
- 严重身份或衣物变化、额外人物、不合理裸露和肢体伪影结果全部在下发前阻断；动态质量阈值和人工裁决规则须在扩量前书面批准。
- 完成动态供应商、关键模型、辅助能力与子处理方的商业许可证审查；研究、非商业或许可证链不清晰的能力不得生产使用。
- 供应商模型升级必须重新跑代表性评测，不能沿用旧版本结论直接放量。

### 地域、隐私与删除门槛

- 图片转动态的实际处理方、地域、输入、最长保留期、训练禁用、取消和删除责任具有可审计证据，并在每次提交前向用户明确展示。
- 中国大陆用户仅可使用获准大陆处理路径；无合规供应商时关闭能力，不自动路由海外。
- 生成中间视频只在完成质量与派生处理所需的最短时间内保留；长期保存或公开分享必须另立目的和需求。
- 删除动态结果、来源静态图、人物、衣物或账号的端到端演练通过，覆盖供应商副本、中间视频、所有视图、封面、设备缓存和后台下载。
- 生产数据不用于训练，隐私政策、App Store 隐私标签和用户举报/处置流程完成评审。

### 成本与生成性能门槛

- 单次任务和单个可交互结果成本不超过商业评审批准的硬上限，并证明重复点击、重放和恢复不重复计费。
- 动态生成端到端 p50/p95、失败率、重试量和供应商容量达到已批准预算；在超时或大面积故障时可立即回退静态图。
- 动态相对静态的增量保留、选定或用户理解价值达到发布评审设定的最低阈值；仅有“看过”或“拖过”不能证明价值。

### 最低设备与无障碍性能门槛

- 已缓存动态资源进入页面到可拖动 p95 不高于 300ms。
- 标准测试网络下首次预览可交互 p95 不高于 2 秒；该指标不包含服务端生成等待。
- 拖动到目标视图反馈 p95 不高于 50ms，连续拖动平均显示帧率不低于 55fps，主线程帧耗时 p95 低于 16.7ms。
- 连续拖动 1 分钟卡顿比例低于 1%，动态预览额外内存峰值低于 100MB；内存警告、磁盘不足和弱网下可回退且不崩溃。
- 页面退出后不继续无意义播放或消耗前台资源；“减少动态效果”、VoiceOver、最大 Dynamic Type 和加粗字体验收通过。

### Feature flag 与发布门槛

- 动态功能拥有独立于静态试穿的 feature flag，默认关闭；可按环境、App 版本、地域、供应商策略和用户比例开启。
- 客户端入口和服务端处理同时受控；任一侧关闭时不创建动态外部任务，并立即使用静态结果。
- 按内部授权账号、小比例用户、逐步扩量顺序发布；每阶段复核误导理解、质量、隐私、删除、成本、生成 p95 和设备性能。
- 出现严重内容漏放、跨用户访问、未授权跨境、训练承诺变化、删除失败、资产复活、崩溃回归或明显误导时立即关闭。
- 成本、生成延迟、质量拒绝或静态降级率持续超过批准阈值时停止扩量，不得通过降低质量或无障碍门槛继续开放。
