# 每日记录与穿搭社区需求

更新：2026-09-30。状态：私人日记/月历为 current_personal_use_scope；公开社区、运营及账号平台为 out_of_scope_current_personal_use。本轮供本人自用、不公开上线，一级入口为“今日 / 衣橱 / 穿搭簿”，私人日记属于穿搭簿中的轻量记录，不新增社区入口。

上位需求：[10-OOTD产品需求](10-OOTD产品需求.md)，研究依据：[29-Woo虚拟人偶与自用成本决策](../design/29-Woo虚拟人偶与自用成本决策.md)。历史 COMMUNITY 前缀保留为稳定追踪身份，不表示当前产品包含社区。旧 approved / 后端验收不能证明本轮 App 私人旅程已完成。

## 目标与当前范围

本人可在穿搭簿写可选的私人图文日记，按月/日期回看、编辑和删除；可以没有衣物、计划、实际记录或模型。同日可多条，未写日记不阻碍 Look 保存、收藏、生成或实际确认。

首版无账号、无需后端、不依赖同步。公开发布、发现/关注流、点赞、评论、审核举报、运营后台、站内/推送通知、注册验证和找回均不纳入。旧云平台合同不会因代码或接口存在自动恢复为后续批准范围。

## 当前可追踪需求

| 稳定 ID | 当前行为 |
| --- | --- |
| COMMUNITY-REQ-001 | 私人图文日记可新增、修改、删除，同日多条；日期与原时区固定，心情/场合可空，不强制衣物或自拍。 |
| COMMUNITY-REQ-002 | 可主动关联本地 LookRevision、计划或实际记录；关联只引用，不自动创建实际、偏好或生成任务。 |
| COMMUNITY-REQ-003 | 月历分别标示 Look 日期条目、计划、实际和日记，点某天看分组列表；实际穿着计数仅来自有效 WearEvent。 |
| COMMUNITY-REQ-011 的本地部分 | 私人图片用途与固定版本可追溯，元数据/文件存本机；不因日记或关联把本人原照上传/公开，坏图不冒充保存成功。 |
| COMMUNITY-REQ-012 的本地部分 | 删日记只处理该记录及不再被引用的自有附件，不自动删除独立 Look、计划或实际；删关联对象不复活私有图/正文。 |
| COMMUNITY-REQ-016 | 单人本地持久化；无账号、无网络能新增、查看、改删和月历回看。稳定 ID、revision 与文件引用支持中断恢复和重复保存保护。 |
| COMMUNITY-REQ-017 | 日记默认私人。导出/系统分享需本人主动选内容并预览，关联的原照、日期、备注不会自动全量带出；不创建公开链接或自动发布。 |

本地日记上限为可调整的初始产品建议：标题可空、最多 80 个字符；正文可空、最多 5,000 个字符；心情/场合各最多 40 个字符；最多 9 张本人主动选择的图片。按用户可见字符计数，不按 UTF-8 字节计数；文字、可读图片或有效 Look 关联至少一项非空。采用的实际限制须在保存前说明，超限明确提示，不静默截断。这些数值不是 Woo 已观察事实或供应商限制，须经本人日常样本和设备验证；不能从旧服务端 schema 假定实现已经支持。

## 功能流程与失败恢复

| 流程 | 前置、正常完成 | 取消/失败/完成断言 |
| --- | --- | --- |
| 写日记 | 穿搭簿主动新增 → 今天/过去日期及原时区 → 可选文字/图/心情/场合或 Look → 明确保存 | 未来日期提示改为计划；取消不创建；空内容或超限保留输入并提示；保存成功有稳定 ID，重启一致。 |
| 加图片 | 系统选图/拍摄 → 本机预览/裁剪 → 明确添加到本条日记 | 拒绝权限、坏图、超数或取消不新增附件；图片未存成功不得宣称整条完整，可移除失败项再确认保存。 |
| 关联穿搭 | 本人从本地历史选择确定版本，可无关联 | 删除/变更关联仅作用日记；不能从 Look 外观推断衣物身份/穿着次数；关联已删显示不可用，不恢复源图。 |
| 月历回看 | 查询原本地日期月份 → 区分四类内容 → 点一天进入分组详情 | 空月份正常；跨时区不改日；Look/日记/计划数量不计为实际，读取失败可重试且不伪造关联。 |
| 编辑 | 从当前稳定 ID/revision 读取 → 修改输入 → 明确保存新 revision | 取消不变更；写入失败保留旧内容与草稿；旧编辑不能覆盖较新版本。 |
| 删除 | 展示“仅此日记及其独有附件” → 确认 → 隐藏并清理 | 取消无变化；附件清理失败可重试，不假称全部清完；不误删其他日记/Look 共用文件。 |
| 导出/系统分享 | 本人选内容 → 看预览与是否包含日期/备注/图 → 明确输出 | 取消无输出；不会自动发布、上传全部日记或创建实际；源图/敏感元数据不被默认包含。 |

未保存草稿与已保存日记分开。数据库元数据和沙盒文件保持可恢复一致：文件准备好才提交可读版本，中断或磁盘不足保留旧版本，不留只有“成功”标记的坏图条目。同一保存重试不复制日记；本人明确新增第二条才生成新 ID。

删除 Look 或本人形象后，日记独立文字继续存在；关联标明已删除，私有图片按其真实来源和删除影响清理，不能用复制快照规避源图删除。若日记仅包含该关联，删除前允许选择保留已删除占位或一并删除日记。删图/清缓存与删整条日记不同，影响须可理解。

## 待验收标准与追溯

- 无账号、无后端、无网络时，可完成新增文字/图/可选关联、编辑删除、重启回看和按月查询；日记不是 Look 保存门槛。
- 同日多条、过去日期、旅行跨时区和午夜边界保持原日期；未保存/失败/重复点击不产生假记录。
- Look、计划、实际和日记标签/数量分开；生成、关联、收藏或写日记不自动创建 WearEvent 或增加穿着次数。
- 相机/图库拒绝、坏图、超限、磁盘不足、进程中断均有可恢复入口；不出现正文成功但附件失败却声称全部保存。
- 日记、共享文件和源形象删除影响正确；迟到写入、缓存或关联快照不能复活已删私有内容。
- 没有社区、账号、审核运营或通知假入口，也没有未经本人动作的上传/公开；系统输出可预览并取消。
- 最大辅助字号、VoiceOver、无图和减少动态效果下可完成私人主要旅程。
