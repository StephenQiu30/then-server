## 当前范围与状态

主线为：本人/风格参考 → 完整穿搭图 → 本人确认 → 按需整套静态 GLB → 本地查看、记录与复用。三预设人物、六套内置模型、账号、公共后端、社区、订阅与上线门禁不再是自用首版条件。

| 状态 | 含义 |
| --- | --- |
| `scope_confirmed` | 用户已确认的产品方向和行为范围；不是实现完成 |
| `candidate` | 模型、供应商或条件方案待本人样本比较 |
| `implementation_pending` | 新合同尚需实现；历史代码存在不能关闭此状态 |
| `real_validation_pending` | 本人照片、满意成本或真机行为没有通过证据 |
| `deferred` | 后续条件能力，未排期；不阻断当前人物与日记闭环 |
| `superseded` | 原编号保留，原行为由当前合同取代；不再执行相反条款 |
| `out_of_scope_current_personal_use` | 当前个人范围不纳入，也不默认在下一阶段恢复 |

旧文档中的 `approved`/`approved_with_gates` 与 completed 结果只按原切片和证据理解，不能套为本轮个人 App 已通过。
