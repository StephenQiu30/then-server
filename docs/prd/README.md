此目录存放产品需求文档。

推荐模板：

```markdown
# 功能名称

## 状态
草案 | 已批准 | 已废弃

## 背景与问题

## 目标用户

## 产品目标

## 非目标

## 功能范围

## 用户故事

## 业务规则

## 成功指标

## 依赖与风险

## 未决问题
```
