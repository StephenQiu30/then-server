# 云端生成与任务管理需求

## 当前范围与状态（2026-09-30）

本版依据本轮 [Woo 虚拟人偶与自用成本决策](../design/29-Woo虚拟人偶与自用成本决策.md)及用户当前授权原地修订。产品为个人自用，不公开上线；目标是本人可辨识、明显虚拟的 Woo 式人偶与每日 Look 记录。当前主线为确认本人/风格参考 → 风格化整套 Look 图片 → 本人确认 → 按需生成整套静态 GLB → 本地保存和复用。

状态：需求修订；供应商、本人样本质量、实际费用和设备表现待验证。本文不宣称 App、真实 API 接入或新版验收已完成。iPhone 仍为目标设备假设，实际手机未确认。既有编号保留，旧账号、公共服务和工程证据不证明本版通过。

### 执行边界

- App 使用本地持久化的 `GenerationJob`、`CostRecord` 与媒体文件；原生网络层使用本人的 API Key 直接请求供应商。Key 保存在原生 Keychain，不传给 WKWebView、JS、页面 URL、导出包或日志。
- 本版不要求产品注册登录、产品云账号、公开后端、SaaS、多租户、消息队列、多设备同步、客服或运营 SLA。个人 API 调用仍需要实际供应商账户/Key 与可用余额。已有后端工程保留在原仓库，但不是本版生成链路依赖。
- 图片和模型是两次独立、主动确认的云动作。图片成功不自动生成模型；模型失败不损坏已确认图、日期、衣物与记录。视频、骨骼动画与固定人偶即时换衣不首做，见 [PRD 14](14-AI虚拟试穿需求.md)、[PRD 15](15-动态预览需求.md)。
- 本地只记录与展示真实处理事实，不保证供应商排队时长、取消、退款、结果永久恢复或远端即时删除。隐私和分层删除以 [PRD 18](18-隐私与数据控制需求.md) 为共用合同。

## 产品目标与用户故事

1. 本人可在不建立产品账号的情况下，查看已有资产、整理衣橱、记录每日 Look；断网或供应商故障不丢本地成果。
2. 每次发送前知道本次输入、实际供应商/模型、处理条件、预计费用和可选附加项；拒绝后不上传、不新建付费任务。
3. 离开页面、App 重启或恢复网络后仍能找到原任务；恢复查询不等于重新提交付费生成。
4. 区分技术产物就绪和本人满意。外观不满意的成功产物可能已扣费，重做须重新确认并计入预算。
5. 取消、删除、结果过期与费用状态分别说明，不以加载超时、隐藏模型或删除本地文件推断第三方停止、退款或清除。

## 提交与输入版本

### 提交前

- 本人/风格参考只是生成约束，不是固定人体资产，也不保证每套脸、拓扑和体形绝对一致。任务记录引用本人参考版本、风格版本、Look/确认图片版本、输入内容标识、供应商、模型、参数及可用 seed。
- 图片任务只传本次选择的人物参考、当天照片或衣物参考和必要参数；模型任务只传已确认、仍有效的 Look 图片及必要参数。不得自动上传整个衣橱、记录正文或原图元数据。
- 原图和已确认图片保留在本机。界面先说明实际发送哪些图及必要裁剪；本地预处理失败不能静默改成上传更多原始输入。
- 发送前再次检查输入版本、删除状态、确认记录、供应商策略与预算；先持久记录提交意图与费用预留，再发送请求。并行提交的检查与预留必须一起完成，不能分别读取相同余额造成超发。
- 同一个提交意图的重复点击返回本地原记录。相同有效输入、版本和参数已有满意产物时直接复用。更换输入或主动重做是新意图，需要重新说明消费。

### 私人密钥与接入

原生侧负责供应商鉴权和 API 访问；WebView 只承担本地 GLB 展示。供应商 Key 不写进源码、数据库普通字段、JS bridge、崩溃报告、请求调试正文或分享材料。本人修改/移除 Key 不删除既有满意资产；使用旧凭据的在途任务也不能被假报为已取消。

未确认创建接口具有幂等保证时，不把本地锁或提交 ID 当成供应商幂等键。若 POST 可能已被受理但响应丢失，保留 `unknown`，核对已知任务 ID、供应商可用历史或账户账单；不能自动新建第二个付费任务。没有可核对接口时明确告知无法自动确认，由本人核实并另行决定。

## 用户可见状态与恢复

状态由本机持久记录及可验证供应商事实共同构成。供应商任务 ID、最后查询时间、下载有效期和费用状态分别保存；供应商内部状态先映射，不直接照抄成产品成功。

| 状态 | 含义 | 可执行动作 / 费用边界 |
| --- | --- | --- |
| `preparing` 准备 | 本地选图、校验、确认和费用预检，尚未发起付费生成 | 换图、取消；未发送的预留可释放 |
| `submitting` 提交 | 已保存意图/预留，正在发送或等待受理回应 | 阻止重复提交；中断时判断是否进入未知 |
| `unknown` 提交结果未知 | 不能确认是否已受理、是否扣费或对应任务身份 | 安全查询/人工核对；不自动重发、不假报失败退款 |
| `queued` 排队 | 已确认供应商接纳并等待执行 | 查询或请求取消；不承诺开始时间 |
| `running` 处理中 | 供应商正在执行原任务 | 查询或请求取消；不得静默切供应商或模型 |
| `downloading` 收取 | 输出已出现，正在下载、完整性与格式检查、本地落盘 | 在有效期内有限重试下载；供应商成功可能已经收费 |
| `ready` 就绪 | 对应文件校验通过并在本机可用 | 对照原图确认满意/拒收，保存或删除；不是相似度保证 |
| `failed` 失败 | 已确认的提交拒绝、执行失败或本地收取失败，原因可解释 | 修正输入或安全恢复；费用按实际事实，不能默认零费用 |
| `expired` 过期 | 已证实结果/取回窗口失效，现有接口不能收取 | 保留已确认图；新生成需重新确认费用，不自动消费 |
| `cancelled` 本机任务已取消 | 本机后续生成/发布已停止，迟到输出不得进入满意库 | 外部停止与费用另列状态；本机取消不保证供应商已停 |

允许的主要路径为 `preparing → submitting → queued/running → downloading → ready`；`unknown` 经真实核对可回到原任务后续阶段或确认终态，不能靠超时直接推断退款。技术就绪后另存本人评价（待确认/满意/不满意），不把美术拒收改写成供应商失败。

### 生命周期与窗口

- App 前台按供应商限制退避查询；离页和系统终止不取消外部任务。首版不以推送、WebSocket或无限后台执行为恢复前提。
- 重启读取本机原任务与原输入，不重新 POST。恢复窗口取决于供应商的查询/输出政策；只有 task ID 不保证结果永久可取。
- 临时链接应及时下载到私有沙盒。签名链接、输出留存和查询窗口可以不同；例如 BFL 官方结果签名 URL 当前有效 10 分钟，是否可重新取回必须验证，不能据此保证永久恢复。[BFL 结果获取](https://docs.bfl.ai/flux_2/flux2_image_editing)
- 查询断网或单次超时只是观察失败，不直接判外部任务失败/过期。过期、失败、已扣费、未知分别显示。
- 下载必须校验对应任务/输入版本、格式与可读取性，并在文件与元数据完成持久化后发布就绪。旧版结果不覆盖新版草稿或其他日期。已下载满意资产按本地保留规则保存，不随远端临时链接到期失效。

## 预算与费用透明

本版用个人预算替换免费次数、商业权益与账号配额；没有订阅、次数包或充值销售体系。

### 价格与用量假设

具体候选报价、月用量场景与成本算术统一维护在 [Design 29](../design/29-Woo虚拟人偶与自用成本决策.md)，[Design 01](../design/01-技术选型.md) 只维护技术选择；本 PRD 不重复金额。研究标价是待实测/提交前复核的候选价格，不是固定收费或质量保证。提交前按实际供应商、模型档位、输出数量、附加处理和当时价格估算。

调研中的月度低用量/全量用量场景只是测算，不是用户已批准预算、不保证满意套数，也不含充值门槛、税费、附加项、人工和安装成本。图片、模型阶段各最多两次是可调整的初始建议；首轮模型两次为直接三维与风格化后三维两条路径合计，P1 少量对照另计。实际限额须由本人设置/确认，不能把建议当成自动消费授权。

### 预算记账与并发保护

- 提交前展示本次预计新增费用、阶段重做次数、月度已确认支出、在途预留及未核对费用；缺少有效价格估算或本人额度设置时先完成说明和设置，不静默发起消费。
- 每笔任务费用区分 `reserved`（预留）、`confirmed`（供应商已确认扣费/不扣费）、`unknown`（可能受理或扣费未明）。估算、账单实值、币种和价格来源时间分别保存，未知不能写成零费用。
- 接纳新提交时检查本人设定上限，并计入已确认支出、在途预留及未知任务保守占用；同笔未知费用仍被预留覆盖时不重复加算，但不能提前释放。提交并发不能超额预留。
- 明确未被接纳且不收费时释放预留；实际结算后用真实扣费替代对应预留。查询失败、取消请求、链接过期或审美不满意不能自行释放可能已发生的费用。
- 本地上限只约束 App 发起的消费，不能控制本人从供应商网站或其他客户端产生的费用；价格/附加处理超出原预估时提示并核对，不宣称本地预算等于供应商账单硬封顶。
- 无静默自动重做、额外输出、高清纹理、分件、low-poly、绑定、格式转换或供应商切换；每项新增消费须明确选择。安全的状态查询/下载有限重试不创建新生成。
- 供应商执行成功但本人拒收通常仍可能收费。系统失败或取消是否免收按实际接口与账单核实；不承诺“没有满意结果就不扣钱”。保留所有付费尝试计算满意每套成本。
- 同一满意模型浏览、旋转、收藏、改日期或关联同套记录不新增生成费用。达到限额时停止新提交，已有任务仍可查询、收取与删除。

## 取消、删除与迟到结果

- 准备阶段取消可直接停止；外部已受理后只能请求取消，并独立保存 `requested/confirmed/not_supported/unknown/completed` 等外部事实。界面可说明“App 后续已停止，外部仍处理中”；不能凭本机 `cancelled` 显示“供应商已停止/已退款”。
- 取消不自动删除原图、已确认 Look 图或仍被其他记录使用的资产。删除是另一项有范围预览的动作；清理与费用核对可以继续，但不得继续生成或发布。
- 删除前列出引用/派生关系，确认后持久记录删除意图，关闭本地读取和新派生。删模型保留图；删图按血缘处理其模型；删本人参考或源照片先说明影响的旧 Look 与结果。
- 迟到输出、乱序状态和恢复下载不得重建已删/已取消资产；仍能核对删除账本的受控备份恢复先应用删除标记。卸载/全部清除后旧外部包无法自动得知后续删除，应预览并由本人明确选择导入范围，如实说明限制。仍需保存最小任务身份、费用和清理状态；不能为了清理而保留被删图片或密钥。
- 本地文件已删、外部删除请求已发、外部已确认、仅按供应商期限到期、状态未知和删除失败分别记录。供应商不提供删除接口时如实说明人工路径或期限；不能把本地删除计为远端清除，详见 [PRD 18](18-隐私与数据控制需求.md)。

## 验证边界与追溯

先在电脑完成一套本人风格化图和可旋转 GLB，再以小样本验证身份、衣物、跨套稳定及满意成本；设备与云处理接受范围尚待本人确认。本人照片不因本次需求修订自动获得上传授权。

新版必须验证：原任务重启恢复；POST 回应丢失不自动重发；并行预算预留与未知费用；输出有效期；图失败/模型失败分层；下载与版本绑定；取消/删除迟到结果不复活；满意产物本地离线复用；真实扣费与无敏感日志。没有已核验供应商功能时，显示缺口并限制相关动作，不承诺公共服务 SLA。
