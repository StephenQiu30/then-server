# 隐私与数据控制需求

## 当前范围与状态（2026-09-30）

本版依据本轮 [Woo 虚拟人偶与自用成本决策](../design/29-Woo虚拟人偶与自用成本决策.md)及用户当前授权原地修订。产品仅本人自用、不公开上线；本人照片、本人与风格参考、风格化 Look 图片、按需静态 GLB 和每日记录默认私有。虚拟化、去脸、抠图或使用 file_token 都不能被表述为匿名或本地推理。

状态：需求修订；本地数据生命周期、真实 API 行为、外部留存和设备验收待验证。原有稳定编号保留；旧账号、公共服务、固定删除 SLA 和禁止本人 GLB 导出的相反正文已替换。旧验收结果不代表新版通过。

当前架构为本地元数据/沙盒文件、原生个人 API 直连与 Keychain 密钥，不引入产品账号、公共后端、多租户、社区、同步或运营服务。具体路线及候选条款/成本集中见 [Design 29](../design/29-Woo虚拟人偶与自用成本决策.md)，任务与预算见 [PRD 17](17-云端生成与任务管理需求.md)。本次修订不上传本人照片、不付费调用，不将调研授权当成具体云处理确认。

## 产品目标

1. 权限只在本人主动使用对应功能时申请；拒绝后保留手工记录、已保存照片/模型和其他不依赖该权限的本地能力。
2. 每次外部图片或模型动作都说明实际输入、供应商/模型、目的、处理条件、预计费用及外部留存事实；图片同意不自动覆盖模型或新消费。
3. 本人可查看本地数据、外部生成历史、有效确认、费用、保留/删除状态并导出自己的资产。
4. 可以分层删除源、参考、图、GLB、Look 或全部本机数据，知道引用和派生影响；迟到结果不复活已删内容，保有删除账本的受控恢复先应用标记。
5. 本地已删、外部已请求、外部确认、期限到期、未知和失败分别表示；不虚构远端即时取消、退款、删除 SLA 或全部副本清除。

## 权限、来源与最少处理

### 本地权限

- 首次启动不批量请求相机、相片库、相册写入、通知或定位。当前记录/展示路径不需要联系人、日历、麦克风、运动或健康权限。
- 主动拍摄才请求相机；系统照片选择器优先使用所选照片，不将整库读取设为前置；主动保存图片到相册才按平台能力申请最少写入权限。
- 本地沙盒保存和系统文件导出不以相册权限为前提。拒绝相册写入仍能本地保存；拒绝通知仍能在 App 内恢复查询任务。
- 拒绝后不循环弹出系统对话框，给出手工路径或本人再次主动选择后的设置入口；不要求重新授权才能访问原有 Look。
- Vision 主体掩膜不等于衣物分割，也不表示隐私已消除。上传画面和必要裁剪须可预览，失败不能静默改成更大范围。

### 本人与照片

人物照片限本人有权处理的素材，不扩展为他人、名人或来源不明人物生成服务。不以产品登录证明本人或年龄，不提供换脸、人物搜索、精确量体、健康/吸引力评价或身份识别库。

选择本人素材时确认来源与当次用途；不继承公共平台的通用成年声明流程。供应商确有年龄、输入或账户限制时，按其已核验条款落实具体条件。多人、缺失全身、遮脸等提示属于输入风险提示，不得宣称 App 已自动验证身份或年龄。授权模板如使用，应标识其素材来源，不要求本人把模板声明为真实自己；模板不是本轮本人形象验收替代品。

发送前剔除非必要 EXIF、位置、设备信息、原文件名等元数据；不得附带整个衣橱、日期记录正文、联系人、精确地址或其他未选历史。生成式侧背补全与真实拍到的视角分别说明，风格化人偶不证明真实合身或实际穿着。

## 本地数据与版本清单

媒体放私有文件，元数据保存固定引用和必要状态；不能仅把模型存成临时网络链接。

| 类别 | 本地保存与用途 | 删除/导出边界 |
| --- | --- | --- |
| 本人原照、当天照片 | 保留本人选入的原图；用于参考或真实记录 | 可私人导出；删源前说明可达派生影响 |
| 本人/风格参考 | `AvatarReference`、`StyleProfile` 版本与参考图；不是参数化人体或身份硬锁 | 更新建新版本，不覆盖旧 Look；删版本按引用检查 |
| 预处理图、蒙版、缩略图 | 当次必要派生与可重建缓存 | 清理缓存不等于删除原图或满意资产 |
| 衣物/Look/穿搭记录 | 选中单品、日期、真实穿搭或试搭标记、本人确认 | 保留独立结构化事实，不因生成失败清空 |
| 满意 Look 图和 GLB | 私有离线资产，GLB 绑定已确认图片版本 | 本人可导出；删模型可留图，删图说明派生模型 |
| 任务与费用 | 原意图/输入版本、供应商/模型、任务身份、状态、费用预留/扣费/未知、取回期限 | 可导出必要元数据；不含凭据/媒体访问 URL |
| 确认与清理记录 | 实际输入摘要、处理政策版本、确认时间、删除范围/阶段 | 最小记录；不能借此保留已删媒体或形象参数 |
| API Key | 原生 Keychain 小型秘密，仅原生鉴权使用 | 不进普通数据库、JS、日志或本人导出备份包 |

数据页逐类显示“本机保存”“已发送给某供应商”“未发送”或“状态未知”；默认不创建云同步状态或跨账号数据错觉。本人设置/导出的位置也可能受系统备份或云盘影响，不能把“保存在本机”扩大为“系统绝不备份”。

## 逐次云动作确认

每次图片或模型实际发送前，界面说明：

1. 本次功能、实际供应商/模型、待发送图和参数摘要；图片任务与模型任务分别确认。
2. 会离开本机的数据及最少必要输入；file_token 仅避免公开图片 URL，仍是供应商处理。
3. 已核验的处理/存储地区、子处理方、输入/输出/元数据留存、训练/人工审阅政策和删除能力；未披露或未知项明确写未知，不能伪造确定事实。
4. 预计消费、输出数量、附加项、本人阶段/月度限制及未知在途消费，细则见 PRD 17。
5. 拒绝仍能使用的本地路径；取消、撤回与外部副本处理限制。

确认仅覆盖当次输入、用途和实际处理条件。原照用于图片生成不自动授权三维、视频、训练、公开分享或评测；图片 ready 也不自动产生模型消费。发送前政策/输入/模型/费用项变化须重新确认，不能静默切换供应商或跨境路线。

关键条款未核验时不默认为已接受或写“不训练/立即删除”；先补充事实或不选该路线。个人自用不取消供应商对本人可识别照片、许可或账户档位的实际限制；向第三方转供生成服务等商业规则不自动当成本人自用的阻断。个人直连只是授权架构，不代表已经取得处理/上传照片授权。

撤回从此阻止该目的的新外部发送，不自动撤销已经受理的生成、退款或清除旧结果。更换/移除 Key 可停止新请求；外部在途处理和副本另行核对。

## 密钥、日志与私人访问

- Keychain 中的个人 Key 只进入原生供应商请求；WKWebView/Three.js 加载本地显示资产，不持有 Key，不以 JS bridge 传递鉴权。
- 不在源码、仓库、普通数据文件、URL、调试打印、错误提示、崩溃报告或导出包记录 Key、Authorization、签名下载 URL、完整请求图片/base64。
- 任务记录可以保存恢复所需的最小供应商任务身份，但普通界面/分享回执不暴露访问凭据；不把任务 ID 一概当作可公开资料。
- 无默认遥测、远程人物浏览、公共链接或公开社区。本人主动系统分享只传所选媒体，不连带发送原图、整库、任务日志和密钥。
- 错误说明展示安全摘要；隐私排查先用合成输入，真实照片网络验证仍需本人当次授权。旧 CI/日志脱敏证据不能替代新版实际请求观察。

## 私人导出与备份

本人可从本地数据页导出自己仍可访问的原照、满意 Look 图、满意 GLB 和元数据；这替换旧版“仅 Look 图片可输出、GLB 不开放”的限制。导出用于本人携带/备份，不需要产品账户或客服，不建立公开下载服务。

- 可选择结构化数据或包含所选媒体的私人数据包；范围预览包含参考版本、Look/日期/真实或试搭标记、资产引用、文件内容标识和必要任务/费用状态。
- 使用可读、可机器处理的元数据与原生媒体格式，说明字段/日期时区；导出清单标记缺失、已删、未收取或远端过期的资产，不为凑齐自动上传或付费重生成。
- 不含 API Key、Keychain 秘密、Cookie、Authorization、签名链接、完整请求/响应调试正文或无关敏感记录；任务身份如非恢复必需不附入分享摘要。
- 本地生成导出包并通过本人选择的系统文件/分享入口交付；说明包含本人照片，第三方接收/云盘是另一外部副本。临时包有清理状态，成功交付不等于所有副本可远程撤回。
- 沙盒持久文件、系统设备备份、电脑手工备份、云盘和系统分享接收副本分别说明控制主体。本版不引入多设备同步或服务器备份，不承诺这些个人外部副本统一到期或自动删除。
- 重新安装/恢复前保留原数据；不因导出失败重建空库，不把包创建成功当成文件交付与可恢复已验证。仍保有删除账本的受控恢复须核对版本、引用并应用删除标记；卸载或全部清除后导入旧外部包无法自动知道之后的删除，须先展示包来源/日期和内容，由本人明确选择导入范围，不承诺自动防复活。

## 分层删除与版本引用

删除前展示对象、关联任务、被引用版本、派生图/模型、共享范围和未自动处理的外部副本；执行前保存最小删除意图。重启继续清理，而不是仅从页面隐藏。更新参考、删缓存、移除 Key 和永久删除分别命名。

| 删除动作 | 当前本机合同 |
| --- | --- |
| 删除 GLB | 清理该模型及专属缓存，保留源图、Look 日期和独立衣物记录；不自动调用重生成 |
| 删除 Look 图片 | 清理图及其可达派生 GLB/缓存，先说明影响的引用；保留不依赖媒体的穿搭事实 |
| 删除本人源照片/参考版本 | 说明所有可达派生图/GLB与历史引用；执行已确认范围，清理复制的私人外观/参考，不保留被删脸/发型/体形参数；独立衣物和事实可保留 |
| 删除衣物照片或记录 | 区分仅媒体、归档与永久删除；说明受影响 Look/派生物，无图手工记录或历史占位由本人选择，不误删独立单品 |
| 删除某日 Look/穿着记录 | 清理当次专属快照/媒体，仍被其他记录使用的独立资产先说明；不默认删除衣橱单品 |
| 删除全部本机 OOTD 数据 | 清理本机数据、媒体、派生物与缓存；是否移除个人 Key 单独说明。供应商副本、个人导出/系统备份不冒充自动清除 |
| 处理外部副本 | 按实际 API、供应商控制台、人工请求或公开期限处理，单独记录是否确认；不以本机删除代替 |

本机删除生效后关闭正常读取与新派生；迟到产物只能按清理规则处理，不得重新发布，旧任务恢复不能重新创建已删源、图或模型。删除账本仍存在时，受控恢复先应用最小删除标记；全部清除账本或卸载后不能自动识别旧外部包的后续删除，限制与导入选择需明确。不能为了证明删除而继续保留原照、参考图、形象参数或访问链接。

版本更新不是删除：新参考版本只作用于新提交，不静默改写历史 Look。共享或被多条记录引用的资产，先展示实际影响；正式删除源及其派生不得留下可显示的旧私人复制。不存在产品账号注销流程，不将“退出登录”当成删除入口。

## 本地与外部清理状态

本机任务取消与数据清理均需区分范围。删除记录至少保存：已请求、已关闭本机读取、本机清理中、本机已清理、外部已请求、外部已确认、等待供应商期限、外部不支持/未知/失败，以及需本人手动处理的备份/导出副本。

- 本机已清理不显示“全部副本已删除”。外部未返回证据或只接受请求时不显示已确认。
- 供应商没有立即删除 API 时说明能力限制和实际留存政策；不编造 5 分钟/24 小时/30–35 天清除 SLA，不以企业级删除合同作为个人实验通用前置。
- “等待期限”必须有已核验政策/日期依据；不能仅因推定日期过去就宣称每个备份已物理擦除。只知政策不知个案时标记“按供应商政策到期，未独立核验”。
- 删输出不一定删请求元数据；两者分别说明。外部任务已受理而本机取消时仍可能处理/收费，见 PRD 17。
- 清理失败保留不可读状态及最小范围/原因，安全步骤可重试；不要为恢复清理再次上传或生成已删除数据。
- 移除 Key、卸载 App、删除本地记录不能保证清除供应商账户数据或其他电脑/接收方副本；未纳入自动范围的副本明确列出。
