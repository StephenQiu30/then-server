# 设计文档

此目录存放产品设计和技术设计。

推荐模板：

```markdown
# 功能名称设计

## 关联 PRD

## 目标与约束

## 用户流程或系统流程

## 页面与状态

## 领域模型和数据流

## 权限、隐私与安全

## 失败与降级方案

## 备选方案与决策
```
