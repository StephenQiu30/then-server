# 设计文档

此目录存放产品设计和技术设计。当前产品需求事实源是 [`../prd/10-OOTD产品需求.md`](../prd/10-OOTD产品需求.md)，技术事实源是 [`01-技术选型.md`](01-技术选型.md)。实现与评审不得继续沿用旧生活管理产品的范围和技术基线。

推荐模板：

```markdown
# 功能名称设计

## 关联 PRD

## 目标与约束

## 用户流程或系统流程

## 页面与状态

## 领域模型和数据流

## API 与存储设计

## 权限、隐私与安全

## 失败与降级方案

## 备选方案与决策

## 测试策略
```

重要架构决策必须说明为什么选择当前方案，以及什么条件会触发重新评估。

## 边界已批准、功能受门禁

- [`14-AI虚拟试穿设计.md`](14-AI虚拟试穿设计.md)：静态试穿的产品与技术边界已批准；只有供应商质量、许可证、地域、删除和成本 POC 通过，并由 feature flag 开启后才面向真实用户启用。
- [`15-动态预览设计.md`](15-动态预览设计.md)：2.5D 动态预览边界已批准；只有静态试穿先达到门槛、动态供应商与性能/合规 POC 通过，并由独立 feature flag 开启后才启用。

设计获批不等于所有能力同时上线。实现顺序、依赖与发布状态由 `docs/plan/` 管理，可执行发布门槛由 `docs/acceptance/` 管理；供应商与跨境处理仍需逐项准入。
