## 边界已批准、功能受门禁

- [`07-AI虚拟试穿设计.md`](07-AI虚拟试穿设计.md)：静态试穿的产品与技术边界已批准；只有供应商质量、许可证、地域、删除和成本 POC 通过，并由 feature flag 开启后才面向真实用户启用。
- [`08-动态预览设计.md`](08-动态预览设计.md)：2.5D 动态预览边界已批准；SwiftUI 容器可在原生帧 renderer 与受控 Three.js renderer 之间按 POC 选择，只有静态试穿先达到门槛、动态供应商与性能/合规 POC 通过，并由独立 feature flag 开启后才启用。

设计获批不等于所有能力同时上线。实现顺序、依赖与发布状态由 `docs/plan/` 管理；某个切片进入开发前，从已批准 PRD/design 生成一份 `docs/plan/FF-SS-*执行计划.md`，其中 `FF` 取单功能 PRD 编号，并在同一文件中统一范围契约、任务与证据。可执行发布门槛由 `docs/acceptance/` 管理；供应商与跨境处理仍需逐项准入。
