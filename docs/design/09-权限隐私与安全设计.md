# 权限、隐私与安全设计

## 状态

草案，2026-08-09。关联 [`../prd/03-最小可行产品需求.md`](../prd/03-最小可行产品需求.md)、[`03-系统总体设计.md`](03-系统总体设计.md) 和 [`08-同步与接口设计.md`](08-同步与接口设计.md)。本文是工程安全与产品隐私基线，不替代正式法律意见、隐私政策或上线合规评估。

## 目标

- 用户在授权前理解用途、范围、不开启的影响和撤回方式。
- 财务、日历、精确位置、票据和认证信息按敏感数据处理。
- 默认最小采集、最短保留和本地处理；当前不上传或长期保留票据图片与原始轨迹。
- 权限拒绝、撤回、账号退出和数据删除都有完整产品路径。
- 防止越权访问、重复写入、敏感日志、临时文件泄露和后台定位滥用。

## 数据分类

| 级别 | 示例 | 基本控制 |
| --- | --- | --- |
| 高敏感 | 交易/分录、日历标题与地点、精确坐标、原始轨迹、票据图片、备注。 | 最小采集、Data Protection、TLS；上云时强制字段级信封加密、严格授权、禁止日志。 |
| 认证秘密 | refresh/access token、Apple 会话凭据、服务端密钥。 | Keychain/KMS、短期、轮换、不可记录、最小权限。 |
| 敏感元数据 | 设备、同步游标、事件时间、行程摘要、错误上下文。 | 目的限定、限期保留、脱敏日志、owner 隔离。 |
| 一般产品数据 | 版本、feature flag、非个性化配置。 | 完整性校验、常规访问控制。 |
| 公开数据 | App 公开说明和无用户数据的帮助内容。 | 发布审核和完整性。 |

“已授权系统权限”“已开启产品功能”“已同意上传/长期保留”是三种独立状态，不能互相替代。

## 权限矩阵

| 能力 | 触发时机 | 请求 | 拒绝/限制 | 撤回后 |
| --- | --- | --- | --- | --- |
| 日历 | 用户点击同步日程 | EventKit Full Access | 手动计划；解释 iOS 无只读授权。 | 停止扫描，不误判来源删除；缓存按用户选择清理。 |
| 通知 | 用户首次启用出发提醒 | UserNotifications | 计划仍保存，页面显示“未安排提醒”。 | 取消/标记本地请求，提供系统设置入口。 |
| 定位 | 规划当前位置或开始行程 | When In Use；精确位置按场景 | 手动起点；无轨迹 Journey。 | 停止新增点，保存 partial 片段，要求完成或继续。 |
| 后台位置 | 用户主动开始实际行程 | iOS 可见后台活动会话 | 仅前台记录或手动摘要。 | 立即结束后台活动，不默认请求 Always。 |
| 相机 | 用户选择拍摄票据 | Camera | 相册或手动输入。 | 不再打开相机；当前识别会话临时图立即删除。 |
| 相册 | 用户选择已有图片 | Photos picker/必要范围 | 相机或手动输入。 | 不影响已确认交易；当前识别会话临时副本立即删除。 |
| 生物识别（P1） | 用户开启 App 隐私锁 | LocalAuthentication | 使用设备口令或不开启。 | 关闭额外 App 锁，不影响系统数据保护。 |

首次启动不批量请求权限。系统设置返回后重新读取真实授权状态，不以本地缓存假设成功。

## 数据最小化

### 默认不采集

- 日历正文、参会人、邮件地址和附件。
- 微信、支付宝、银行 App 私有流水或通知内容。
- Apple 地图的导航历史、收藏、偏航和到达状态。
- 未由用户主动开始的全天位置。
- OCR 无关区域的长期图片副本。
- 用户金额、商户、标题、地址或坐标的产品分析明文。

### 默认仅本地

- EventKit 原始标识及 HMAC 映射。
- OS 权限状态和系统通知 request ID。
- OCR 中间结果与会话临时图。
- 原始 TrackPoint。
- 未登录用户的账本、计划、Journey 和关系。

### 账号启用后的可选同步

- 账户、交易、用户确认计划、Journey 摘要和不涉及日历来源身份的正式关联。
- OCR 图片、票据原图、原始轨迹点和轨迹文件始终不进入当前同步范围，不提供保存或云备份开关。

日历同步到云的字段清单必须独立批准；默认只允许用户已确认的计划字段，不上传原始事件正文、EventKit 标识、HMAC 映射、CalendarOccurrence、`EventTripLink` 或 `TransactionEventLink`。这些事件关系在 P0 和当前 P1 同步范围内都仅存在本机。

## 本地安全

- access/refresh token 和长期凭据存 Keychain，不存 UserDefaults、SQLite 或日志。
- GRDB 数据库文件使用 `completeUntilFirstUserAuthentication` Data Protection，兼顾锁屏行程可靠写入；实际文件保护在真机验证。
- 原始轨迹、OCR 临时图和导出文件继承合适的文件保护，并使用随机不可猜文件名。
- P0 不默认使用 SQLCipher；若威胁模型要求设备解锁后仍对数据库内容二次保护，再评估字段加密或数据库加密及其后台写入影响。
- P0 只允许一个本地资料档案。未来若支持同机多账号，每个账号必须使用独立数据库文件和独立密钥；退出账号后先关闭数据库并清除内存中的查询结果，不能让后一账号打开前一账号的本地数据。
- App 切入后台时隐藏敏感快照；可选隐私锁进入 P1。
- 剪贴板只在用户明确选择复制地址/内容时写入，不复制金额或令牌。
- 调试菜单和诊断导出不得包含原始敏感正文。

## 网络与服务端安全

- 所有生产网络使用 TLS；禁止明文回退和忽略证书错误。
- 认证中间件从 token 得出 user ID；请求 payload 中的 owner 字段不作为授权依据。
- Repository 的每个用户数据查询都包含 owner 条件；关系创建校验两端同 owner。
- 创建和同步使用幂等标识，更新使用 base version，防止重放和覆盖。
- 使用请求体大小、分页、速率和并发限制，避免同步资源耗尽。
- refresh token 轮换、设备撤销和会话审计摘要进入服务端安全基线。
- 数据库和备份开启静态加密；KMS 权限与应用身份最小化。
- 所有上传的财务明细、用户确认的日历衍生上下文、精确地址/坐标与敏感元数据必须使用字段级信封加密：按用户和数据域生成 DEK，由 KMS KEK 包装；密钥版本随密文保存，支持轮换与账号删除时的密码学擦除。票据图片与原始轨迹当前不上传。
- 只有 owner、实体 ID、类型、状态、版本、cursor、时间桶和幂等处理所需的最小操作元数据可按批准 schema 明文保存。服务在严格授权后可于内存中短暂解密进行领域校验，明文不得进入日志、trace、缓存或错误响应。
- 在可搜索加密、受控聚合或等价方案通过专项威胁评审前，服务端不提供商户/备注/地址搜索，也不计算需要解密明细的报表；P0 搜索与报表全部在 iOS 本地执行。不能为了服务端功能降低加密要求。
- 后端部署、PostgreSQL 和 KMS 优先同一中国大陆地域与私网连接。

## 临时图片与轨迹

- 票据图片只在一次 OCR 会话内存在；确认、取消、权限撤回或会话异常结束后都删除，不复制到长期目录。
- 原始轨迹只服务于活动行程恢复和摘要计算；摘要确认或行程丢弃时与状态变更同一事务清理。
- 两类临时数据均不建立附件实体、不进入导出、mutation、OpenAPI、服务端 schema 或云备份。
- App 启动时扫描异常遗留的临时文件，并按可验证规则继续当前会话恢复或安全清理；清理失败必须可见且可重试。

## 日志、指标与追踪

允许记录：

- request ID、route template、HTTP 状态、稳定错误码、耗时、重试次数。
- 队列长度、cursor 延迟、数据库池指标、临时清理结果和构建版本。
- 不可逆聚合后的功能结果计数，前提是分析方案获批。

禁止记录：

- access/refresh token、Apple credential 和服务端密钥。
- SQL 参数、请求/响应敏感正文。
- 金额明细、商户、备注、日历标题、地点、精确地址、坐标和轨迹。
- APNs payload 业务正文和票据 OCR 原文。

OpenTelemetry trace attribute 使用路由模板而非完整 URL；日志脱敏在业务数据进入 logger 前完成，不能依赖采集平台事后过滤。

## 通知与锁屏隐私

- 本地出发提醒默认使用最小文案；用户可选择是否显示事件/地点。
- APNs payload 只包含不透明 ID、类型和同步唤醒所需最小字段，不包含金额、标题、地址或轨迹。
- 通知深层链接打开后仍执行本地/服务端授权检查。
- Focus、系统调度和用户设置可能阻止展示，App 只报告“已安排”而非“已送达”。
- 当前只使用普通本地通知，不启用 Time Sensitive 或 Critical Alerts，也不保留隐藏开关。

## 生命周期与保留

| 数据 | 默认方向 | 删除触发 |
| --- | --- | --- |
| OCR 中间图 | 识别会话内本地临时 | 确认、取消或会话过期后删除。 |
| 日历窗口快照 | 本地滚动窗口 | 来源取消选择、权限撤回后的用户选择、窗口过期。 |
| 用户 TripPlan/Journey 摘要 | 用户删除前保留 | 显式删除或账号擦除。 |
| 原始轨迹 | 活动行程期间本地临时 | 摘要确认或行程丢弃时立即删除；异常退出仅保留到恢复处理。 |
| mutation receipt/tombstone | 至少覆盖最长离线期 | 所有有效设备确认或批准期限后。 |
| 脱敏服务日志 | 有限运维窗口 | 到期自动清理。 |
| 备份 | 按 RPO/RTO 和隐私承诺 | 到期轮换；账号删除按披露期限清理。 |

具体天数必须由产品的最长离线、恢复和删除承诺决定，再成为配置和验收常量，不由实现人员自行选择。

## 导出

- 用户可以导出账户、交易、分录可读视图、计划、Journey 摘要和关联。
- 票据图片和原始轨迹不提供导出选项，也不能通过诊断包或分享流程绕过。
- 导出使用临时受保护文件，分享完成/取消后及时清理。
- 导出不包含 token、内部 HMAC、mutation、服务端审计或其他用户数据。
- 生成失败不破坏源数据；低存储时提供分批导出。

## 删除

### 分层删除

- 清理 OCR 临时数据。
- 丢弃进行中/待确认 Journey 的临时轨迹，或删除整个 Journey。
- 清理日历缓存并停止同步。
- 删除本机全部数据。
- 删除云账号和全部云端数据（账号启用后）。

每个入口明确会保留什么。例如删除 Journey 不删除正式交易；清理日历缓存不删除用户创建的计划。

### 账号删除状态

`requested -> deleting -> deleted | failed`。请求后停止非必要新云写入并撤销普通设备会话和推送；若存在撤销期，只保留一个仅能查询/取消删除的受限管理会话，或每次通过 Sign in with Apple 重新认证。进入 `deleting` 后撤销全部会话，由同进程任务清理主表、关联建议、冲突暂存、mutation receipt、change log、tombstone 和死信。状态和截止时间必须明确；失败保持可重试与人工诊断，不向用户提前宣称完成。

备份清理时限和不可立即擦除的法定/安全记录必须在隐私政策中说明。

## 主要威胁与控制

| 威胁 | 控制 |
| --- | --- |
| 丢失或借用已解锁设备 | Data Protection、可选 App 隐私锁、后台快照遮罩、可撤销会话。 |
| IDOR/跨用户访问 | 认证上下文 owner、Repository 限定、复合外键、集成测试。 |
| 重放导致重复记账 | mutation/幂等键、服务端规范化 payload 的带密钥摘要、唯一约束和事务。 |
| 客户端时钟篡改 | 服务端 version/cursor；客户端时间不决定冲突。 |
| 敏感日志和追踪泄漏 | 结构化 allowlist、无正文、测试扫描日志字段。 |
| 后台位置滥用 | 用户主动开始、明显状态、When In Use、可停止、无全天采集。 |
| 临时图片或轨迹残留 | 受保护临时目录、随机文件名、会话结束清理、启动恢复扫描和失败可见。 |
| 删除后数据复活 | tombstone、cursor、设备撤销、全量恢复协议。 |
| 供应商 SDK 过采集 | P0 最少第三方 SDK；接入前审计权限、数据清单、地域、关闭方式。 |

## 第三方与供应商准入

新增地图、云 OCR、分析、崩溃或存储供应商前必须记录：

1. 必要性与无 SDK/端侧替代。
2. 收集字段、目的、频率、地域和保留期。
3. 用户同意与撤回路径。
4. SDK 初始化时机和隐私 API。
5. 数据处理协议、子处理者、删除与导出能力。
6. 密钥、配额、退出和替换方案。
7. 真机网络抓取和隐私清单验收。

供应商未批准前通过接口隔离且默认关闭，不在领域层引用厂商类型。

## 安全测试与发布门槛

- 授权矩阵：未登录、当前用户、其他用户、已删除和已撤销设备。
- 幂等、版本冲突、重放、越权关联、cursor reset 和同机账号数据隔离。
- 日历/通知/定位/相机/相册的拒绝、限制、撤回和系统设置返回。
- 日志、崩溃、trace、通知和诊断包敏感字段扫描。
- Keychain、文件保护、锁屏快照和后台轨迹真机验证。
- 导出完整性、临时文件清理、本地删除和账号删除端到端证据。
- 依赖漏洞、固定版本、SBOM/依赖清单和第三方隐私清单审查。
- 生产 Swagger 默认关闭，调试端点不暴露敏感配置。
