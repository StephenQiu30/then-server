# App 账户与云端访问执行计划

## 状态、目标与追踪

2026-09-22；契约 `approved`，执行 `pending`。用户授权本轮 PRD/Plan 拆解；本片尚未开发。它是 14-01 与 19-07/08 共用的 App 云访问前置，不能让社区依赖付费模型 POC，也不能以登录为离线 Look 前置。

依据 [Design 15](../design/15-账号认证与账户数据设计.md)、[Design 23](../design/23-后端接口设计.md)、[PRD 17](../prd/17-云端生成与任务管理需求.md) 的 ACCOUNT-REQ-003～011、DELIVERY-REQ-002/004，及 PRIVACY-REQ-001/005～007。验收新增 ACCOUNT-ACC-011，联验 CLOUD-ACC-002/010、OOTD-SYS-ACC-008/013；质量 OOTD-NFR-001/004/006/007/010～013。

## 现状和交付边界

账号注册/登录、Cookie、本人 CRUD、限流/会话撤销、资料与可靠删除已有后端证据；App 尚无真实 Cloud Client。本片只接实际账号/公开资料操作和必要会话基础；媒体/任务 operation 分别由消费者切片加入，不提前生成所有领域模块。

登录后本地无账号数据不会自动成为账号云数据。只对用户发起的云动作传最小输入；完整同步、邮箱验证/找回、头像和多设备会话列表仍需后续能力切片及生产门禁，不能用目前接口假造按钮。公开注册发布仍取决于邮件、地域与治理等准入；受控集成可用测试账号。

## 用户可见合同

| 状态/动作 | 成功行为 | 失败与取消 |
| --- | --- | --- |
| 访客从头像或明确云动作进入 | 登录/注册后返回原草稿；不会自动重放付费生成或发布动作 | 关闭登录返回本地；原 Look/衣橱/记录可继续；不在启动弹全屏强制登录 |
| 会话建立与恢复 | 使用服务端现有 Cookie 合同；受保护持久会话和当前账号绑定，重启验证后恢复 | 不将 Cookie/token 放 UserDefaults/GRDB/日志；无效会话清除，普通登录失败不误删已有有效会话；不得另加自创 JWT/Bearer 协议 |
| 读取/修改本人资料 | 读取服务事实，修改携 expected revision，提交成功再更新页面 | 409保留编辑并提示重新载入，422定位字段，429显示等待，503可重试；网络错不显示已保存 |
| 会话过期/退出 | 401清当前云会话，原账号重新登录后找回原任务/草稿；显式退出撤销服务端会话并清本机云身份/可控私有缓存 | 离线退出可先清本机，但不能宣称服务器会话已撤销；需记录待完成撤销或明确说明，不能复用旧 cookie 自动发用户动作 |
| 切换账号 | 按 owner 隔离任务、缓存、云草稿与延迟回调；新账号重新拉其数据 | 前一账号的图片/日记/后台响应不得显示；已有无账号本地衣物不无提示合并上传 |
| 删除账号 | 显示影响并确认；按实际 202回执区分访问关闭、清理中与已完成；退出本人云态，保留独立本地无账号事实 | 请求未接纳不误报成功；再次提交同意图去重；当前无公开进度查询 API 时不得反复请求不存在的端点或虚构进度 |

服务端删除回执的完整性优先于用户表删除顺序；沿用 19-06。若产品需要注销后持续查询进度，必须先补经验证的最小查询合同，再开放该显示能力，不能把 202 当所有副本已删。

账号 Repository 无生成/日记业务逻辑；网络 adapter 只负责传输、Cookie、类型化结果，不持有 UI 导航；ViewModel 只在当前账号仍一致时发布异步结果。首次检查点是一个真实登录→本人读取→退出→旧会话拒绝的闭环，建议 1～2 工程人日检查，再扩状态和删除。

## 验证、证据与回退

先验证运行时 API 和生成差异，再按 11-05 的 iOS build/test/xcresult 步骤执行账号测试。后端未改业务时沿用对应证据，仅回归实际 HTTP；若发现契约缺口并修改 Huma/GORM，则按 17-29/19-06 跑相关 Go、真实服务与进程门禁。真机验证会话存储、锁屏/重启、系统网络失败和 VoiceOver；不在证据中暴露Cookie。

关闭 App 云入口即可回退；保留本地 Look/衣橱/记录及服务端清理任务。新旧客户端不得混用账号作用域；不清库恢复页面。当前未选择/安装 Client 生成依赖、未运行后端或 App、未启用线上账号。
