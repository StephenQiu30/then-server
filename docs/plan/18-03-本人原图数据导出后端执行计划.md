# 本人原图数据导出后端执行计划

## 状态与范围

- 契约：`approved（本地合成数据）`；实施：`completed（后端）`。接续 [18-01](18-01-数据主体导出与删除回执合同执行计划.md) 和 [18-02](18-02-本人数据导出后端执行计划.md)，仅改 `then-server/backend` 及同一事实源文档。
- `POST /exports` 开放 `with_media`。沿用当前会话、当前密码再验证、限流、任务、私有 ZIP、本人下载/撤销及 24 小时开发期过期清理；不新增服务或公开对象链接。
- 媒体只取该 owner 的 `ready` 用户原始 JPEG 固定版本：本人照片、私人日记普通图片和社区上传普通图片。`source_deleted_at` 已设置或读取时已丢失的源图列入遗漏并给出 `partial`；已删除/撤销读取权的媒体不打包。衣物图用途尚未启用，衍生图片、公开副本、GLB、视频和未上传设备数据不补造。
- ZIP 媒体条目固定为 `media/<media_uuid>.jpg`，先核对字节数和 SHA-256；manifest 标明文件摘要、计数和逐项遗漏，不写对象 key/version 或用户自选文件名。单包 32 MiB 上限，超限按既有有限重试/失败合同处理；只读 OCI 内用有界内存，不依赖可写临时目录。
- 单张媒体删除在同一 PostgreSQL 事务中撤销该 owner 尚可读的媒体档导出，后台清理包的全部版本；注销已有的整体撤销规则继续适用。客户端展示与真实用户发布仍属独立验收。
