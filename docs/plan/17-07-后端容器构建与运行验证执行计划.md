## 范围契约

使用既有 Go 1.26.5 编译 `cmd/then-server/main.go` 对应的 `./cmd/then-server` package，构建一个静态 Linux binary。多阶段构建的最终 scratch 镜像仅包含 binary、CA 证书及模块清单；默认 UID/GID 65532，不包含 shell、Go 工具链、源码、环境文件或测试照片。17-19 后同一镜像支持 `api|worker|all`；worker/all 只有在合成本地媒体配置完整时才能启动。

本地测试以只读 rootfs、cap-drop ALL、no-new-privileges、256 MiB 内存、64 PID、1 CPU 运行。预算不作为生产容量承诺。实际镜像连接隔离 PostgreSQL/Redis/MinIO/RabbitMQ，验证 API live/ready、三角色启动与 SIGTERM；缺失媒体门禁的 worker 继续失败关闭。

不改 OpenAPI、业务数据、迁移、app 模块或云能力开关；不引入 Compose 集群、管理后台、第二个二进制、自动 migration 或线上镜像推送。
