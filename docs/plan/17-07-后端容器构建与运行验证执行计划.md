## 范围契约

使用既有 Go 1.26.5 编译根 main.go，构建一个静态 Linux binary。多阶段构建的最终 scratch 镜像仅包含 binary、CA 证书及模块清单；默认 UID/GID 65532，不包含 shell、Go 工具链、源码、环境文件或测试照片。容器显式设置 HTTP_ADDR，默认行为沿用现有配置；api 可用，worker/all 继续拒绝启动。

本地测试以只读 rootfs、cap-drop ALL、no-new-privileges、256 MiB 内存、64 PID、1 CPU 运行。预算只作为本次健康 API 的测试限制，不作为生产容量承诺。实际镜像连接隔离 PostgreSQL，验证 live/ready、SIGTERM 退出及非法角色拒绝。

不改 OpenAPI、业务数据、迁移、app 模块或云能力开关；不引入 Compose 集群、管理后台、第二个二进制、自动 migration 或线上镜像推送。

## 失败、资源与回滚

测试镜像名显式传入，缺失直接失败，不自动拉取任意后端镜像。PostgreSQL 使用 17-01 相同固定 digest 与随机合成凭据。API 与 DB 由测试清理，仅本地 loopback 共享网络用于隔离明文 DB 连接，不推广到生产。生产 DB 仍要求 verify-full。

本切片未写业务数据；回滚为停止测试容器、移除本次本地镜像及回退构建文件。测试镜像不发布。正式发布仍需完整 SBOM/许可证/漏洞、生产 TLS/容量/可用性及 Swift 契约构建门禁，本次模块清单不是完整 SBOM。
