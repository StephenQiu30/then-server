# 私人日记与月历客户端执行计划

## 状态与追踪

2026-09-22；契约 `approved`，执行 `pending`，本轮仅文档拆解。承接已完成的 19-03 API，交付 App 私人日记→月历回看的一个端到端切片。依据 [PRD 19](../prd/19-每日记录与穿搭社区需求.md) COMMUNITY-REQ-001～003/011/012、[Design 21](../design/21-后端产品边界与领域设计.md) 私人记录合同；验收 COMMUNITY-ACC-001/002/009/012。质量 OOTD-NFR-004～007/010～013。

## 输入、行为与边界

- 用户登录账号后从穿搭簿进入私人日记；无需先有衣服/Look/实际事件。一日多条，选择不晚于当地今天的日期，保留原日期/时区；标题/正文/心情/场合/图片按 PRD 19 和运行时 API 限制。
- 支持新建、详情、编辑/取消和删除；普通日记图片经用途专属上传/检查/净化后关联固定媒体版本。未通过的图片不能假显示上传成功。
- 日记可关联本人已存在计划/实际事件；当前缺少云 Look 关联接口时保留无关联写日记，不能创建假 cloud ID。Look 关联在 14-01 有对应实体后才接入，不阻断日记切片。
- 月历分别显示计划、实际穿着、日记数量；当前 App 本地计划/实际和账号日历不能合并为一个未经去重的总数。切片采用明确的账号日历范围，其他本地记录仍在原列表；完整同步另立合同。
- 无网可保留本机受保护编辑草稿，必须标为“尚未保存到账号”；本片不建设后台自动双向同步。恢复网络后用户主动保存，幂等键与 expected revision 保证一次结果。
- 删除日记先显示其图片/关联影响；独立已发布帖子不随之删除，取消无变化；删除实际事件只解除关联。注销/切账号不能显示前账号日记或草稿。

## 检查点、验证与回退

第一检查点（建议1～2工程人日）为无图日记的真实创建→重启读取→删除，再加图片/日历和故障恢复。执行17-30的真实API/Client检查及11-05的iOS build/test/xcresult步骤，关联真实PG/MinIO验收；本片无付费生成。

验收必须提供账号数据前后差分、图片用途/访问与清理记录、月历日期fixture、错误恢复和VoiceOver录屏。显示过一次日记不等于已保存；模拟器通过不代替真机文件保护。

回退隐藏新日记入口但保留用户私人数据与删除路径，不删除现有后端日记表；不能为了清理缓存连带移除用户已保存日记。本轮上述编码与运行时验证均未执行。
