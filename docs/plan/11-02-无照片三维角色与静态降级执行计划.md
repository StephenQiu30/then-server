## 工具、资源与系统边界

开源复用复核：GLTFLoader/SkinnedMesh/morph 复用锁定 Three.js 实现，不把本片扩成自研 glTF/蒙皮引擎。正式人物使用 Blender 5.2.1 LTS 可编辑母版和随发行版导出器，Khronos validator 用于离线标准校验；现有预编译 GLB 只作工程/异常夹具。工具选定不等于资产通过，ASSET-01 与 SEC-01 状态仍按证据推进。

- 仓库不保留建模或导出脚本。Blender `.blend`、原始贴图、source revision、许可证和 SHA-256 是生产事实源；GLB、manifest 和报告是发布产物。开发期本地持久化源资产并备份到私有 MinIO，App 运行不访问对象存储。
- Three.js 固定 `0.185.1`；只使用 WebGLRenderer/WebGL 2 与本地 GLTFLoader 所需源码。官方发布包和实际使用文件均锁定来源/完整性/哈希，交付依赖锁文件、MIT/NOTICE、SBOM 和更新说明。若需要新增 Node、包管理器或构建器，先退回相应工具任务，回写 Design 01 后再批准，不能用系统最新版本临时打包。
- GLB 仅允许内嵌 buffer、有限蒙皮/morph 和批准的 PBR PNG/JPEG 贴图；禁止外部 URI、未知扩展、WASM/压缩解码器或脚本。纹理/几何超预算时再评审单一压缩路径。未知参数/rig/资源/hash/字节数先拒绝再加载。
- 隔离 SwiftUI 测试壳不链接生产 RootView、不注册生产入口，不形成第二套产品架构。WKWebView 仅为 Services/Rendering 对应职责的局部画布；产品状态、控件、保存与删除均在 Swift。
- 非持久 WebKit 数据存储；HTML/JS/模型离线打包，严格 CSP；拒绝外联、导航、弹窗与下载，不用 eval/new Function。原生先验证资源，通过会话内不透明句柄交付；JS 不接收个人身份、业务 ID、原路径、令牌或 URL 凭据。
- bridge 消息上限 64 KiB，字段固定、枚举化、数值必须有限；使用 session UUID + 单调 revision，返回必须匹配两者。重建会话后旧 revision 即使数值相同也不得复用。
- 隔离持久化固定 GRDB + 系统 SQLite、受保护专用测试目录，配置与派生图分离；不访问当前 OOTD 数据库、不追加生产 migration。不预建账号、OpenAPI、后端、队列、Provider、真实照片或衣物生产映射。

## 测试、预算与判定

1. 生产资源：`.blend` source revision、原始贴图与许可证可追踪；同一输入重导差异可解释；GLB schema、索引/权重、骨架与 morph 长度、有限数值、双上装不同几何及全部支持组合验证。工程夹具不要求充当可编辑美术源。
2. 预算沿用 Design 13 的待校准提案：全场景 ≤80k triangles / 8 材质槽 / 30 draw calls，≤64 关节且每顶点≤4 权重，每 primitive 同时活跃 morph ≤8；压缩增量≤30 MiB。没有纹理的样本不得冒充复杂纹理生产压力通过。
3. 真机目标：30 次冷开 p95≤2 秒，100 次换装 p95≤300 ms，触摸到呈现 p95≤100 ms；10 分钟操作 p95 帧间隔≤33.3 ms、>100 ms 帧<1%。相对静态页增量峰值≤150 MiB、候选整体≤300 MiB；明确 App/WebContent/GPU 归因口径，不能只报告 JS 计数。
4. 恢复：快速 A→B→C、取消/退出后迟到、会话重建、加载一半失败、WebContent 终止/context lost、删除与导出预览竞态。当前画面必须匹配当前会话/revision；100 次进出后无持续资源增长，稳定释放后相对基线增长≤10%。
5. 数据：同版本重启恢复；事务失败保留草稿；写图成功/事务失败和事务成功/图失败均可恢复；删除后数据库、私有文件与内存无原配置，内置资源和其他测试数据不误删。
6. 无障碍：原生按钮/滑块完整可操作；Reduce Motion、VoiceOver、减少透明度与故障静态路径分别记录。纯静态或模拟器截图不抵扣真实三维/真机验收。
7. 证据记录工具链、源码/资产 hash、命令、设备/build、夹具、步骤、结果与限制；不能只报“正常”。模拟器 Go 只允许继续开发，不能批准物理发布。
