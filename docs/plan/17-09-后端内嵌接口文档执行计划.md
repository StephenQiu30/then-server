## SMART目标

- Specific：以现有 Gin API 承载 Swagger 与运行契约，退役独立文档容器；Swift 生成输入不变。
- Measurable：下面 ACC-01 至 ACC-07 全部有可复现证据；新功能 Go 单元/race、真实进程/PostgreSQL、浏览器和生成链路均验证。
- Achievable：沿用固定 Go/Gin、Swagger UI 与 Swift Generator，不新增框架、数据库模型或生产外部访问。
- Relevant：减少前后端契约协作所需运行服务，避免工作树文档与运行 API 的版本错位。
- Time-bound：本次工作迭代交付；首轮 60 分钟内完成核心实现与首轮验证，若有失败在同一计划记录原因、下一动作和复核点，不以时间到期冒充完成。

## Spec范围与行为

API_DOCS_ENABLED 默认 false，只接受 true/false。true 仅允许 HTTP_ADDR 为 loopback IP；不合法配置启动即失败且错误不打印原始配置。main.go 显式向 NewRouter 注入 bool；不增加可选参数兼容旧调用，各调用点一次改完。

关闭时 `/docs/`、文档资源和 `/openapi.yaml` 都是已有标准 404。开启时仅 GET `/docs/`、`/docs/swagger-initializer.js`、`/docs/swagger-ui.css`、`/docs/swagger-ui-bundle.js`、`/docs/LICENSE`、`/docs/swagger-ui-bundle.js.LICENSE.txt` 与 `/openapi.yaml` 可读，方法错误保持 405；不新增旧地址重定向、目录浏览或文件路径参数。`/openapi.yaml` 必须复用 router 校验的原始字节。资源不存在或打包错误不能伪报文档可用。

Swagger 只加载同源资源；关闭 Try it out、validator、鉴权持久化与 queryConfigEnabled，设置同源 CSP。固定资源和许可证嵌入二进制，哈希清单用于供应链完整性检查；不经运行时网络下载 JS。

无业务 API/schema、GRDB、服务端 migration、用户数据、媒体、认证或云权限变化。数据库仍按原启动/故障语义运行；文档不绕过数据库启动。Swift 插件/DTO 不变，单模块冲突仍归 17-01，不用 Go 通过掩盖 App 构建失败。
