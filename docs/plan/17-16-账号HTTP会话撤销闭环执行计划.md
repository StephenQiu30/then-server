## Spec 与 MVP 边界

本切片只收口实际 HTTP 进程中的会话撤销行为：注册建立会话；退出删除当前会话；已撤销 Cookie 重放得到 401 并被浏览器清除；重新登录后删除账户会级联删除全部会话，旧 Cookie 与旧凭据均不可恢复账户。受保护端点遇到无效、过期或已撤销 Cookie 时返回相同安全错误并发送过期 Cookie；普通登录失败不能清除现有有效会话。

运行时 OpenAPI 为受保护 operation 的 401 声明 `Set-Cookie` 响应头。实现保持 `transport → service → repository` 边界，不增加新 API、表、兼容分支、脚本、Redis 会话源、前端或云上传/任务能力。

## SMART 完成条件

- Specific：只修复无效会话在服务端已拒绝、浏览器却继续携带旧 Cookie 的状态不一致。

- Relevant：关闭 `ACCOUNT-ACC-004/005` 的后端 HTTP 缺口。
- Time-bound：本切片完成代码、integration、Go 全门禁和远程 CI 后结束；生产认证门禁继续独立管理。
