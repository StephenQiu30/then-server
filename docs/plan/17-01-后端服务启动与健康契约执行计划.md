# 后端服务启动与健康契约执行计划

## 状态与追踪

契约 approved，执行 completed（开发运行基线）。Design 02/14 → PRD 17 → 本文件 → [验收 17](../acceptance/17-云端生成与任务管理验收.md)。当前实际接口源是 Huma operation；schema 为 GORM record/AutoMigrate。

## Spec

- 单一二进制、APP_ROLE=api；未知角色启动失败，不创建空 worker。
- 监听前校验配置、连接 PostgreSQL 并集中 AutoMigrate；失败退出，不报告就绪。
- GET `/v1/health/live` 表达进程存活；GET `/v1/health/ready` 表达数据库与排空状态。依赖故障时 ready=503，恢复=200，live 保持反映进程状态。
- 健康请求/响应、错误与 operationId 由运行时 OpenAPI 声明；拒绝不支持的请求载荷和方法。
- SIGINT/SIGTERM 先停止接纳、限时排空并关闭连接；日志不含 DSN、凭据或业务正文。
- App 本地功能不自动调用健康接口；当前无 App 云请求模块。
