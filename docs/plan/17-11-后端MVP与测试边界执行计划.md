## 目标与非目标

本切片固定 B0 后端运行底座与 B1–B3 路线图，将测试环境解析、测试专用依赖和真实服务测试从生产运行边界中明确隔离。该切片完成时普通构建不导入 MinIO、RabbitMQ、Redis 或 Testcontainers；后续 [17-17](17-17-账号认证Redis限流执行计划.md) 因真实账号限流业务将 Redis 加入运行时，MinIO、RabbitMQ 与 Testcontainers 仍只在对应测试图中。services 测试只连接 loopback 并拥有独立资源。

不新增业务 API、数据库 schema、`APP_ROLE=test`、第二个 Go module、测试微服务、脚本、容器常驻测试 runner 或 CI 配置；不启动云账号、上传、生成、同步。

## 用户可见与系统契约

用户可见行为、OpenAPI 和 App 均不变。开发者获得四个独立测试入口：unit/contract、services、integration、container。生产环境变量不会被测试隐式读取，测试变量以 `THEN_TEST_` 开头；services 目标必须是 loopback。
