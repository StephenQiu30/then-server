## 可交付合同草案

顶层 `frontend/` 提供响应式注册、登录、账户读取/修改/删除和退出。请求代码只由 `@umijs/openapi` 读取本机 API 从同一组 Go operation 与类型标注生成的 `/openapi.json` 后生成；页面不复制业务规则，不新增 BFF，不要求 App 登录。

基础切片已迁移到 Next.js App Router，保留 Tailwind CSS、TanStack Query、Axios 适配器、Umi 生成客户端、lockfile 与质量命令。账户页面按 [Design 16](../design/16-Web账户管理设计.md) 的桌面/移动布局和状态矩阵实现。

2026-09-22 基础规范已由 [17-27](17-27-Web设计体系与工程规范同步执行计划.md) 同步为 shadcn/ui + Radix Primitives；下表 17-13-BOOT-02 保留当时接入证据。

## 迁移、失败与回滚

- Web 不拥有数据库 migration；服务端合同由 17-12 提供。
- 生成失败、审计命中高危漏洞、页面稿未批准或浏览器主旅程失败时不发布静态入口。
- 回滚只撤销前端静态发布；不回滚已独立验收的账户 API 与数据库 migration。
