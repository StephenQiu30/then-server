## 可交付合同草案

批准后新增顶层 `frontend/`，实现响应式注册、登录、账户读取/修改/删除和退出。请求代码只由 `backend/openapi.yaml` 生成；页面不复制业务规则，不新增 BFF，不要求 App 登录。

当前只固定审查内容，不创建页面、依赖、生成物或 lockfile。开工前须完成页面稿和状态矩阵审核，并由用户批准本合同。

## 迁移、失败与回滚

- Web 不拥有数据库 migration；服务端合同由 17-12 提供。
- 生成失败、审计命中高危漏洞、页面稿未批准或浏览器主旅程失败时不发布静态入口。
- 回滚只撤销前端静态发布；不回滚已独立验收的账户 API 与数据库 migration。
