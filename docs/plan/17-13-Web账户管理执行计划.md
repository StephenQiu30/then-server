## 可交付合同草案

顶层 `frontend/` 的可运行基础工程与生成请求层已获批准；响应式注册、登录、账户读取/修改/删除和退出仍须在页面合同批准后实现。请求代码只由 `@umijs/openapi` 读取本机 API 从同一组 Go operation 与类型标注生成的 `/openapi.json` 后生成；页面不复制业务规则，不新增 BFF，不要求 App 登录。

当前基础切片已按 2026-09-16 用户要求从 Vite/React Router 迁移到 Next.js App Router，保留 Radix UI、Tailwind CSS、TanStack Query、Axios 适配器、Umi 生成客户端、lockfile 与质量命令。账户页面开工前仍须完成页面稿和状态矩阵审核，并由用户批准该部分合同。

## 迁移、失败与回滚

- Web 不拥有数据库 migration；服务端合同由 17-12 提供。
- 生成失败、审计命中高危漏洞、页面稿未批准或浏览器主旅程失败时不发布静态入口。
- 回滚只撤销前端静态发布；不回滚已独立验收的账户 API 与数据库 migration。
