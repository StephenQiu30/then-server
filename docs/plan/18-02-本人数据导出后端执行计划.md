## 最小接口与状态

| operationId | 方法/路径 | 合同 |
| --- | --- | --- |
| `createDataExport` | `POST /exports` | 当前会话、当前密码和 `structured`；限流、再验证后 `202` 返回 ID/状态/过期时间；`with_media` 在 18-03 前明确拒绝；不返回 ZIP 或存储路径 |
| `getDataExport` | `GET /exports/{id}` | 仅当前 active owner，返回状态、类别计数、遗漏原因和过期时间 |
| `downloadDataExport` | `GET /exports/{id}/content` | 仅当前 active owner 的 `ready` 且未过期包；服务端流式 `application/zip`，无公开/签名 URL；`partial` 随 18-03 媒体档位加入 |
| `revokeDataExport` | `DELETE /exports/{id}` | 仅当前 active owner；先撤销读取权，再清理私有对象，重复撤销幂等 `204` |

一个 PostgreSQL 持久任务记录 owner、模式、状态、最小计数/遗漏、私有对象 key/version、创建/完成/过期/撤销时间及有限重试信息。任务由 API 角色后台循环认领；进程重启后继续，多个实例不重复发布。制作以一致的 PostgreSQL 快照读取当前本人数据；将最多 32 MiB 的结构化内容放入有界内存，使用标准库 ZIP/JSON，成功后写 MinIO 私有固定版本，再原子发布状态。发布前再次核对账号仍 active 且任务未撤销；删号事务立即撤销该账号所有导出任务，清理循环删除所有尝试的对象版本。24 小时到期自动撤销读权并重试清理，已清理的任务元数据在开发环境保留 7 天后删除。

结构化内容采用固定文件名和每领域显式字段 allowlist；manifest 包含 schema 版本、UTC 导出时刻、原记录时区、类别计数、文件 SHA-256、未启用/仅本机类别与因故遗漏类别。记录稳定排序；不读取密码散列、会话/邮件挑战、内部对象 key、签名 URL、Outbox/Inbox 或第三方私人正文。ZIP 使用固定安全条目名，不采纳文件名输入。大包或对象故障标记明确失败，不修改原记录。

使用现有 `application/account` 的会话与密码校验能力；新导出用例归单独语义 package，PostgreSQL record/事务归 `adapter/postgres`，MinIO 私有包方法归 `adapter/objectstore`，四个 Huma operation 的 contract/routes/handlers 归 `adapter/httpapi`，bootstrap 只组装和管理后台循环。无需新微服务、消息 topic、第二套 OpenAPI 或通用 repository。
