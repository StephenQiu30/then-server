## 追踪与范围契约

Design 05「2026-09-13无图衣橱首个实现切片」→ PRD 12 的 WARDROBE-REQ-001/002/009/014 及 005/008 的无图子集 → 本计划 → WARDROBE-ACC-001/004/008 的本片子集、系统 ACC-002/003。原功能验收仍覆盖照片/归档/历史/推荐，不得整体勾选通过。

1. 今日/衣橱原生入口共用领域与 Repository；七类和四种状态、名称校验/稳定 UUID/来源/revision/时间遵循 Design 05 当前合同。无图保存、编辑、筛选、单件删除、重启可用。
2. 单个 OOTD DatabasePool、WAL、集中版本化 migration；只建实际衣物表，GRDB Record 不越过 Data 边界。create 幂等、update/delete revision 复核，事务保证失败不半写；所有 SQL 参数绑定。
3. 全新受保护存储；不读旧库、不创建账号或 Keychain、不上传、不预建媒体/历史表；OpenAPI、后端、生成模块和锁版不变。
4. SwiftUI + Observation，精确注入 Repository；starting/ready/recoverableFailure 启动状态，真实 I/O 离开 MainActor。保存失败不丢草稿，重复保存受状态和事务约束，取消不写入；恢复不自动清库。
5. 删除先确认；当前无媒体/历史，secure_delete + checkpoint 收敛本库 WAL；清理失败可重试并如实显示。未来数据关系加入前扩展删除，不承诺物理闪存擦除。
6. 系统原生列表/表单/筛选/空态，String Catalog、Dynamic Type/VoiceOver 语义和后台隐私遮罩保持；无不可用照片/云端/模型入口。
