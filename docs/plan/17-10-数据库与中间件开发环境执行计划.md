## Spec与边界

本次交付直接使用本机已安装、只监听本机的 PG/MinIO/Redis/RabbitMQ 开发环境。服务测试默认连接标准 loopback 端口，通过进程环境覆盖自定义连接，不读取项目 `.env`。标准命名 Compose 文件只提供显式隔离备用：随机秘密写入忽略文件、权限 0600，使用独立资源与端口，不清理本机服务或其他项目。Go API 从本机 PG 启动，Swagger 沿用内嵌方案。MinIO 仅用合成数据、私有桶；本机或容器发行版均不构成生产选型风险关闭。

验证 PG 事务回滚，S3 私有读写删除，Redis TTL 自动失效，Rabbit quorum queue 的 publisher confirm、手工 ack 与 requeue 重投递。每个测试有超时、随机资源名和清理，外部依赖不可达/鉴权失败必须失败，不能跳过当通过。单节点 Rabbit 不验证 HA；业务 Outbox/Inbox、租约/fencing、生成/取消/删除竞态归后续切片。

## 迁移、恢复与回滚

没有业务 schema，不调用 AutoMigrate、不改 OpenAPI/iOS/历史数据。测试 PG 只用事务内临时表。开发服务停止/重启保留卷；密码文件缺失而旧卷存在时不自动重建秘密。回滚用 down 停止本项目，保留数据，移除本次代码/依赖；删除卷必须是后续明确动作，不提供默认 destructive reset。
