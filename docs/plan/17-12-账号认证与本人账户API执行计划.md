## 可交付合同

本切片交付邮箱密码注册、Cookie 会话、本人账户读取/更新/删除和退出。App 本地核心不要求登录。账户删除硬删除当前开发数据；不保留旧 schema、旧接口或兼容分支。Web 页面由后续 [17-13](17-13-Web账户管理执行计划.md) 承接，本切片不创建 `frontend/`。

完成条件：OpenAPI、Atlas versioned SQL、Go 分层实现与契约测试落地；Go unit/race/vet、真实 PostgreSQL 集成、Swift 生成 Client 编译和敏感信息复核通过。公开流量所需邮件验证、找回密码、Redis 限流和生产 TLS 仍为独立门禁。

## 迁移、失败与回滚

- migration 首次引入业务表；应用身份不执行 DDL。失败时修正未发布 migration 并重建开发测试库，当前无历史数据迁移。
- 注册任一步失败整体回滚，不留下无凭据用户或无主会话。邮箱冲突为 409；无效登录统一 401；无效/过期 Cookie 清除后返回 401。
- 发布回滚先停止新流量并撤销账户入口；数据库若已经承载真实用户，不执行破坏性 down，采用恢复点或前向修复。本开发切片可重建隔离数据库。
