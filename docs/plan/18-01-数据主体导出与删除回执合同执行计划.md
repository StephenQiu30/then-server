# 数据主体导出与删除回执合同执行计划

## 状态与范围

- 对应 `BL-DATA-01`、`PRIVACY-REQ-005/006/008`、`PRIVACY-RULE-008/012～020` 与 `PRIVACY-ACC-005/006/007`；状态 `draft / pending`。处理目的仅为用户主动请求查阅/取得自身数据及核对删除结果，不含生成、分享或分析。本文件先盘点 `then-server/backend` 的现有数据与缺口，不批准导出 API、临时文件或公开删除回执实现。
- 当前用户要求先做后端；Web、App、正式送达和云生成功能不在本片实现。首版离线 Look 与本地衣橱/推荐/记录的数据不会自动上传到后端，也不能被服务端导出包声称覆盖。
- [PRD 18](../prd/18-隐私与数据控制需求.md) 明确要求法务、隐私与产品负责人批准结构化数据、用户提供媒体、生成结果和法定请求补充路径后，才能批准数据导出切片。用户主动请求是导出的触发条件；已有云生成或分享同意不能代替导出请求，撤回外部处理同意也不能关闭导出与删除入口。当前尚无范围签署；保留与过期的具体时限、部署地域和外部副本也尚无批准值。

## 当前代码事实（2026-09-23）

`backend/internal/adapter/postgres/schema.go` 当前迁移 38 张表。可由现有 owner 关联的候选数据分组如下；这是工程盘点，不是获批的导出字段清单。

| 分组 | 当前来源 | 待确认边界 |
| --- | --- | --- |
| 账号与公开资料 | `users`、`user_profiles` | 邮箱、资料及账号状态；不包含密码散列、会话令牌或邮件挑战 |
| 衣橱与穿搭 | `wardrobe_items`、`outfit_plans/items`、`wear_events/items`、`wear_feedback` | 保留当前事实、历史快照、删除占位及原日期/时区；不把计划当实际穿着 |
| 私人日记 | `diary_entries/media` | 仅本人仍可访问的结构化记录与受控媒体；删除墓碑是否作为用户数据需批准 |
| 社区活动 | `posts/revisions`、本人互动与举报/申诉 | 公开版本和本人草稿分开；第三方个人信息、审核内部理由与通知字段需逐项审定 |
| 同意与媒体 | `self_adult_declarations`、`consent_records`、`media_assets/derivations`、`deletion_requests` | 同意/撤回和对象元数据可盘点；原图/衣物图、自有衍生图与对象 key/签名 URL 不可混同 |
| 删除回执 | `account_deletion_requests` | 现有状态仅 `pending/complete`，无账号删除后的公开查询凭据、分阶段结果或已批准的留存期 |

当前 `DELETE /users/me` 返回一次性 `202` 回执并立即撤销会话；删除请求与账号无 FK，物理删号后内部仍可更新到 `complete`。现有 `GET /deletion-requests/{id}` 是**单媒体**删除回执，不能代替账号删除查询。服务器尚无 `/exports` 实现、导出产物表或账号删除后的本人查询入口；云生成任务与完整 Look 也尚未落库。用户设备内未上传数据不属于服务端事实。

## 待批准的最小合同

1. **请求人与再验证**：明确活动账号怎样在导出前重新证明本人，登录会话的有效窗口与高敏感媒体的加强校验；删号后查询只能使用单独的短期回执凭据或获批替代机制，不能接受裸 UUID 充当长期访问凭据。
2. **类别与字段**：逐表确定本人可导出字段、需排除的内部/第三方字段、媒体种类、删除占位和明确的排除原因；结构化数据与“结构化数据+仍可访问的用户提供媒体”两档，绝不借主动 Look 分享入口替代。
3. **交付与状态**：机器可读格式、schema 版本、字段说明、计数、原时区和媒体清单；准备中、可取、部分可用、失败、过期、撤销的真实状态。产物仅本人短时受控读取，可撤销；临时对象、备份及失败残留的实际时限须先批准。
4. **删除回执**：明确访问已撤销、自有系统清理、外部副本、备份到期与需要处理等阶段的事实来源；现有 `pending/complete` 只能用于当前已验证的自有系统闭环。注销后查询的验证方式、最小回执字段和保存期限需单独批准。
5. **安全与失败**：导出过程中删号、撤销、账号切换、并发请求、对象删除失败时不得跨 owner 取数或留下可用链接；不在日志/公开 DTO 中输出媒体 key、签名 URL、凭据、供应商正文或内部安全规则。

上述合同获批前，不创建新表、接口、任务、临时包或客户端下载入口。后续实现复用现有 Huma 运行时 OpenAPI、GORM 事务、私有对象存储和账号鉴权，按需要拆最小切片；不得先造第二套 schema 或万能导出器。
