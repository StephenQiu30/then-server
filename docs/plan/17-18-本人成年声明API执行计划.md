## MVP Spec

本切片只建立“当前账号是否已确认当前声明版本”的权威事实，不上传媒体、不调用 Provider、不启动 RabbitMQ/MinIO，也不把该声明当作第三方 AI 逐次同意。

- 当前政策版本固定为 `self-adult-v1`；政策版本改变时须更换服务端常量并要求重新确认，不做旧版自动兼容。
- `GET /privacy/self-adult-declaration` 返回当前版本及本人状态；未确认是 200 的明确 `confirmed=false`，不用 404 猜测状态。
- `PUT /privacy/self-adult-declaration` 只接受当前版本与 `confirms_self_and_adult=true`；重复确认不重写时间，撤回后重新确认会产生新的确认时间。
- `DELETE /privacy/self-adult-declaration` 撤回当前版本；重复撤回幂等，返回 `confirmed=false`。
- owner 只来自 HttpOnly 会话 Cookie；无效会话统一 401 并清 Cookie。请求和日志不包含出生日期、证件、照片或自由文本。
- GORM 表按 `user_id + policy_version` 唯一保存确认与撤回时间，账号删除时级联删除。当前是无历史数据开发阶段，不增加 SQL migration 或兼容分支。

## SMART 与验收映射

- Specific：只交付当前用户的声明查询、确认和撤回。
- Measurable：3 个稳定 operationId，运行时 OpenAPI 可见；单测、race、真实 PostgreSQL 及实际 HTTP 进程通过。
- Achievable：复用现有会话、GORM AutoMigrate、Huma 错误契约和独立 tests。
- Relevant：落实 `CLOUD-RULE-001`、`PRIVACY-RULE-001/009/010/012` 的服务端前置，为以后上传/任务受理提供明确门禁。
- Time-bound：本切片在代码、真实依赖、实际进程和远程 CI 通过后结束；真实用户云流量仍受 Provider/地域/保留/删除门禁。
