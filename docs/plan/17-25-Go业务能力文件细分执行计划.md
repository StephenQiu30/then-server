## Spec

目标结构遵循 Go 官方 `cmd/internal` 约束、Kratos 分层、Fleet bounded context 纵向切片、Gin resource route 与 GORM 显式事务：

- `cmd/then-server/main.go` 保持唯一薄入口；
- `application/<feature>` 继续拥有模型、规则、用例和最小 port；
- HTTP 社区能力分为 contract、routes、handlers 与 social 对应文件；
- PostgreSQL 社区能力分为 records、posts、moderation、feed、relationships、comments、notifications 与 helpers；
- 不为本次整理新增兼容 alias、DI 框架、BaseRepository、第二 module 或独立 test 服务；
- package 内单元/合同测试与 `tests/{services,integration,container}` 的真实依赖边界保持不变。
