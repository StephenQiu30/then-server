## 目标

在不要求用户上传人物或衣物的前提下，交付三套固定可爱成人形象、六件内置衣物、24 套有效 Look 与每套正/侧/背三视图。用户能够选人、选衣、Dress up、切换视图并保存，默认 Look 离线可用。

本切片先选择内容生产方案并建立首个代表渲染集，随后再进入后端目录和 App 页面实现。内容生成工具不成为 App 运行时依赖。

## 非目标

- 不制作、修复或导出 Blender、GLB、VRM、骨架、蒙皮和布料物理。
- 不实现连续任意角度旋转或身体参数编辑。
- 不接收用户衣物图片，不在 Dress up 时运行生成模型。
- 不在本切片实现本人照片试穿、Create 360°、下载或系统分享。
- 不增加仓库脚本、手工 OpenAPI 文件、第二个 Swagger 服务或通用 Provider 框架。

## 固定产品规格

| 项目 | 契约 |
| --- | --- |
| 人物 | `short-bob-pink`、`double-bun-mint`、`half-ponytail-blue` 三个稳定 ID；人物、发型和衣着为项目自有或已授权内容 |
| 衣物 | 两件 tops、两件 bottoms、两件 shoes；每个 slot 必须且只能选择一件 |

| 离线包 | 每个人物一套默认 Look，共 9 张视图图片及必要目录缩略图 |
| 保存 | 保存 avatar revision、六件目录中的实际选择、recipe hash、render-set revision；不保存临时 URL |

## 用户状态契约

| 状态 | 用户看到 | 允许动作 |
| --- | --- | --- |
| 默认离线 Look | 当前人物默认三视图和目录 | 换人物、切视图、选择衣物、保存 |
| 选择草稿 | 已选衣物托盘和未应用标记 | 逐件替换/移除、取消、Dress up |
| 正在解析 | 真实目录/下载状态，不显示虚假百分比 | 取消并保留上一有效 Look |
| 已应用 | 完整三视图原子替换 | 切视图、保存、收藏、查看详情 |
| 不支持组合 | 具体缺少哪个已发布组合 | 返回修改选择；不临时拼图或生成 |
| 下载失败 | 上一有效 Look 与可重试原因 | 重试、取消、继续离线默认 Look |
| 资源损坏 | 上一有效 Look，坏 revision 被隔离 | 重新下载；不能显示部分新视图 |

## 内容生产和发布契约

1. 先核查每家 API 对人物参考、上装/下装/鞋、多视角的实际输入支持；若需分步合成，明确顺序、身份/衣物漂移与累计成本。单上装 API 成功不能记完整 recipe 成功，不支持目标则 no-go。代表 POC 固定三套人物、两套完整代表穿搭 recipe 和正/侧/背，共 18 张候选；每套 recipe 均含上装、下装和鞋，FASHN API 与 Google VTO 使用相同输入矩阵。
2. 记录输入 hash、模型/API 名称、版本、seed、时间、费用、输出 hash、保留/删除结果和人工修复时间。
3. 两名复核者独立检查人物身份、发型、肤色、身体比例、衣物轮廓/颜色/图案、肢体、背景和三视图一致性。
4. 候选仅在 18 张严重缺陷为 0、非严重修复不超过 2 张、三视图身份全部通过时 go。
5. 完整组合按同一固定 pipeline 生成；每个 recipe 必须三张同时发布，禁止部分发布。
6. PostgreSQL 写业务元数据，MinIO 存媒体字节；对象桶私有，只返回短期签名 URL。
7. 默认 9 张图片从同一发布 revision 加入 App 包；包内和远程 manifest 使用同一 hash 合同。

## API 与存储边界

- Huma operation 与 Go struct tag 是 OpenAPI 唯一来源；Swagger/Umi 从运行中服务读取 `/openapi.json`。
- 最小接口是人物目录、衣物目录和按 recipe 解析渲染集；客户端不能传 owner 或对象 key。
- `LookRenderSet` 只有 `draft`、`reviewing`、`published`、`revoked`。API 只返回 `published`。
- 发布事务必须确认三个视图资产均存在、hash 唯一且 object metadata 匹配，再切换 active revision。
- App 先下载临时文件，验证 MIME、像素、字节数和 SHA-256 后原子 rename；失败清理临时文件并保留旧 revision。
- 目录读取不接 RabbitMQ；Redis 不保存发布事实。后续 Create 360° 才新增异步 `GenerationJob` 和 RabbitMQ 投递。

## 隐私、版权与安全

- POC 和首版内容生产只使用项目自有或已授权的成年人物参考与内置衣物，不读取真实用户素材。
- 供应商请求中不包含账号、设备、真实姓名、联系人、定位或相册元数据。
- 每个参考与输出记录来源、授权、条款快照、pipeline revision 和人工修改；Woo 截图只用于研究，不打包、不训练。
- CatVTON、IDM-VTON、OmniVTON++ 及许可不明的 VTON360 不得成为产品依赖。
- 日志只记录内部资源 ID、任务状态、耗时和错误码，不记录签名 URL、Base64 或对象 key。

## 完成判定

本计划只有在 24 套 Look 的 72 张视图全部发布、目录/解析/缓存/保存的真实纵切完成、模拟器与最低真机验收通过、回滚演练成功后才可标记 `completed`。研究完成、单个候选效果好、Swagger 可见或模拟器一条路径通过都不等于切片完成。

Create 360°、本人照片、下载和分享由后续独立切片承接，不能在本计划中以占位按钮或假状态提前实现。
