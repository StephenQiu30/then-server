## 验收范围

本次只验收技术选型是否已经明确、版本文件是否可被工具读取、现有契约和目录是否符合基线。Xcode 工程、Go 服务、数据库业务表和系统能力尚未创建，不在本次通过范围内。

## 验收环境

- macOS，Asia/Shanghai，2026-08-09。
- Xcode 26.6，Build 17F113。
- Xcode 内置 Swift 6.3.3；`swift format` 6.3.0。
- Go 1.26.5 darwin/arm64。

## 验收场景

### 场景：工具链版本被仓库固定

- 前置条件：在仓库根目录执行命令。
- 操作步骤：运行 `scripts/verify-toolchain.sh`；读取 `.xcode-version` 与 `backend/go.mod`。
- 期望结果：Xcode 为 26.6；Go module 为 `github.com/StephenQiu30/then/backend`，language 为 1.26.0，toolchain 为 go1.26.5。
- 边界情况：本机工具链不一致时脚本必须失败，不能静默使用 beta 或更新版本；CI 尚未创建，因此暂未证明远程 runner 强制执行。
- 验收证据：当前机器执行脚本退出码为 0；Xcode 26.6/17F113、Swift 6.3.3、Go 1.26.5 与 module 指令检查通过。
- 结果：passed

### 场景：OpenAPI 只有一份事实源

- 前置条件：仓库文件完整。
- 操作步骤：解析 `backend/openapi.yaml`；执行 `test -L ios/ThenApp/openapi.yaml` 和 `readlink ios/ThenApp/openapi.yaml`；搜索第二份 OpenAPI 文档。
- 期望结果：规范版本为 3.1.2；符号链接目标为 `../../backend/openapi.yaml`；除该链接外没有第二份 YAML/JSON 契约。
- 边界情况：失效链接、复制文件、`api/` 目录或 Swagger 注解契约均失败。
- 验收证据：人工验证 passed。Generator tag `1.13.0`（commit `af9a2a1f5dcfb00a278d4bb29c6d75080932e99e`）执行 `swift run --package-path <generator-checkout> swift-openapi-generator generate --config ios/ThenApp/openapi-generator-config.yaml --output-directory <temp-output> backend/openapi.yaml`，退出码 0 并生成 `Types.swift` 与 `Client.swift`；持续 CI 仍为 pending。
- 结果：passed

### 场景：单 module、单进程结构约束成立

- 前置条件：仓库文件完整。
- 操作步骤：统计 `go.mod`；搜索名为 `api`、`worker`、`migrations`、`queries` 的后端目录，以及 `cmd/api`、`cmd/worker`、`cmd/migrate` 引用。
- 期望结果：只有 `backend/go.mod`；不存在被禁止的目录和独立入口；当前尚未创建 `main.go` 的事实在 README 中明确。
- 边界情况：文档示例中把禁用结构描述为现状也视为失败；仅在“明确不采用”语境中出现不失败。
- 验收证据：只发现 `backend/go.mod`；被禁止目录与独立入口搜索无结果。
- 结果：passed

### 场景：数据库事实源适配声明式流程

- 前置条件：`backend/schema.sql` 存在。
- 操作步骤：检查文件是否包含完整 DDL 占位说明，是否禁止 P0 未受 Atlas Community 管理的对象；确认没有其他 schema 或 migration 文件。
- 期望结果：只有一个 `backend/schema.sql`；P0 限于 enum/table/column/constraint/index/comment；已有库只管理专用数据库的 `public` schema，任何 DROP 默认阻断，人工确认和生产禁用 auto-approve 已写入设计。
- 边界情况：应用启动时自动改 schema、生产直接执行 `psql` 作为增量升级器、无评审 `--auto-approve` 均失败。
- 验收证据：只发现 `backend/schema.sql`；schema、AGENTS、后端 README 和技术基线约束一致。
- 结果：passed

### 场景：固定项、排除项和待决项没有互相矛盾

- 前置条件：根 README、AGENTS、iOS/Backend README 与技术基线存在。
- 操作步骤：搜索 iOS 最低版本、GRDB、Go/PostgreSQL/OpenAPI 版本、地图默认实现、云厂商状态和被排除框架。
- 期望结果：所有文档指向同一基线；云厂商和分析平台仍为待业务决策，国内地图、云 OCR 与穿搭明确不进入当前实现。
- 边界情况：把高德/阿里云等待定供应商写成已选、为国内地图或云 OCR 预建 SDK/接口，或同时声明 SwiftData/Core Data 为主存储，均失败。
- 验收证据：版本与供应商状态全文搜索、Markdown 本地链接检查和 `git diff --check` 均通过。
- 结果：passed

### 场景：Xcode 工程落实 iOS 基线

- 前置条件：`ThenApp.xcodeproj` 已创建。
- 操作步骤：检查 build settings、Package.resolved、Build Tool Plugin、Compile Sources 并执行 clean build/test。
- 期望结果：最低 iOS 18、Swift 6、Complete Strict Concurrency、四个 Exact package 版本、OpenAPI Client 可重新生成并编译。
- 边界情况：生成文件被提交、契约被复制、依赖自动升级或存在第二套网络 Client 均失败。
- 验收证据：`xcodebuild` 输出与解析后的 Package.resolved。
- 结果：pending

### 场景：Go 服务落实后端基线

- 前置条件：`backend/main.go` 和真实服务代码已创建。
- 操作步骤：运行 `gofmt` 检查、`go mod tidy`、`go mod verify`、`go test ./...`、`go vet ./...` 和 `govulncheck ./...`；启动服务验证健康与优雅退出。
- 期望结果：固定依赖版本、一个入口、无生成 Go API 文件、测试全部通过、进程能在超时内干净退出。
- 边界情况：独立 Worker、ORM、未拥有的 goroutine、日志泄露敏感数据均失败。
- 验收证据：CI 日志、依赖清单和退出测试。
- 结果：pending

### 场景：系统能力通过真机 POC

- 前置条件：日历、定位、通知、导航和 OCR adapter 已实现。
- 操作步骤：按实施计划分别执行权限同意/拒绝/撤回、锁屏、后台、断网、Apple 地图打开失败与 OCR 低置信度场景。
- 期望结果：每项都有可恢复降级；不会把第三方导航调起误报为行程同步；OCR 不直接生成已确认账目。
- 边界情况：模拟器结果不能替代真机；APNs 不能作为唯一准点提醒；P0 不请求全天 Always 定位。
- 验收证据：脱敏录屏、系统日志、耗电与字段准确率报告。
- 结果：pending

## 已知限制

- 当前没有 Xcode project、Go `main.go`、业务 schema 或 CI，因此只能完成技术基线静态验收。
- 账号与多设备同步、国内云和分析平台尚未获得业务输入；国内路线供应商、云 OCR 与穿搭推荐不进入当前实现。
- 单一 PostgreSQL schema 策略只适合当前 P0 约束；复杂生产数据演进需要重新评审。

## 最终结论

技术基线静态验收 passed。Xcode 工程、Go 服务与真机 POC 三类场景保持 pending，直到对应实施里程碑交付；这不代表业务功能已经完成。
