## 验收场景

### PRIVACY-ACC-001 无照片核心与按需权限

- 覆盖需求：`PRIVACY-REQ-001`、`PRIVACY-REQ-003`。
- 前置条件：干净安装，相册、相机、通知、日历和位置权限未决定。
- 操作步骤：启动并使用无图衣橱—推荐—记录闭环，仅在主动选图时处理系统权限，再拒绝/撤回。
- 期望结果：首启不索要无关权限；拒绝后始终有等价本地替代；撤回不删除已保存的结构化数据。
- 边界情况：权限限定访问、系统设置外部更改和离线时 UI 立即一致更新。
- 验收证据：真机权限录屏、网络抓包和 UI 测试。
- 结果：`pending`

### PRIVACY-ACC-002 成年本人、多人和来源边界

- 覆盖需求：`PRIVACY-REQ-002`。
- 前置条件：准备本人、多人、来源不明和明确非本人的合成夹具。
- 操作步骤：不做年龄声明使用无照片核心与授权虚构成人预设；在首次选择本人照片和含本人照片生成前分别尝试进入；替换夹具。
- 期望结果：本地无照片核心不将登录当作年龄证明，也不要求照片声明；授权虚构成人预设校验来源但不要求声明为本人；首次本人照片/相应生成前要求 18+ 本人主动声明；多人、他人、名人、未成年人或来源不明真实人物素材不继续。
- 边界情况：策略/同意版本变更或声明失效后必须重新确认；不执行会输出敏感人体判断的自动年龄估计。
- 验收证据：状态机/UI 测试、合成夹具报告和声明版本记录。
- 结果：`pending`

### PRIVACY-ACC-003 目的分离、同意有效性与撤回

- 覆盖需求：`PRIVACY-REQ-004`。
- 前置条件：本地处理、单次云生成、同步、分析和训练目的被分别配置。
- 操作步骤：只同意其中一项，拒绝其他项，过期同意版本，再撤回已同意项。
- 期望结果：同意不捆绑、不默认预选、不由一次选择推导其他目的；撤回阻止新处理且不伪装已发生处理已撤回。
- 边界情况：同意文案、Provider、地域、保留期或策略变更时原同意不自动延续。
- 验收证据：同意记录查询、版本测试和网络抓包。
- 结果：`partial`。17-19 的 `avatar_source_preparation/person_photo/Then/local-development/person-photo-v1` 固定同意、12 路并发创建幂等、撤回阻止新上传及尚未开始的对象处理已用合成数据通过；其他目的、策略升级与 App 文案仍待验。

### PRIVACY-ACC-004 Provider、地域、训练禁用与云发布门

- 覆盖需求：`PRIVACY-REQ-004`、`PRIVACY-REQ-008`、`PRIVACY-REQ-010`。
- 前置条件：目标市场的 ProcessingPolicy、Provider 合同、子处理方、地域、保留与删除证据已批准。
- 操作步骤：在获批/未获批地域发起任务，使 Provider 不可用，检查请求配置、日志和流量。
- 期望结果：系统默认不跨境回退，不换用未批准 Provider，生产数据不用于训练；上游记录不完整时云功能必须关闭。
- 边界情况：任一批准过期、合同变更或删除演练失败时结果为 `blocked`，不允许灰度。
- 验收证据：准入清单、合同/配置快照、抓包和地域负向测试。
- 结果：`blocked`

### PRIVACY-ACC-005 数据清单、用户审计与理解度

- 前置条件：用户拥有本地结构化数据和不同阶段的云资产/任务。
- 操作步骤：打开隐私与数据控制入口，查看类别、目的、位置、处理方、保留和删除状态，进行可用性/理解调研。
- 期望结果：清单与实际 schema、对象存储、Provider 和缓存血缘一致；文案不用“优化”或“已处理”掩盖真实目的/状态。
- 边界情况：无云账号、离线和部分删除中均能说明已知事实与不可验证部分。
- 验收证据：数据流对账报告、用户理解记录和无障碍录屏。
- 结果：`pending`

### PRIVACY-ACC-006 导出完整性、失败与过期

- 覆盖需求：`PRIVACY-REQ-006`。
- 前置条件：导出 schema、完整性规则、安全交付和过期时限已批准。
- 操作步骤：执行成功、部分失败、中断和过期导出，校验结构、计数、时区、媒体 manifest 和敏感字段排除。
- 期望结果：只有完整包成功交付后显示完成；失败不删除或改写原数据；过期后读权失效并清理临时包。
- 边界情况：导出不包含令牌、签名 URL、Provider 正文、内部密钥或过量运营审计记录。
- 验收证据：schema 校验、完整性报告、失败注入和交付/过期日志。
- 结果：`partial（本地合成数据的两档后端）`。39 表空库迁移、29 类显式字段查询、两账号 owner 隔离、当前密码再验证、Redis 故障关闭、ZIP manifest/摘要/时区说明、MinIO 私有版本、撤销/过期/清理、任务租约重领与并发认领、删号后迟到发布拒绝已由专项服务测试验证。18-03 进一步验证原图固定版本覆盖后仍准确打包、源图已清理时 `partial`/遗漏/下载、删图事务撤销旧媒体包及对象全版本清理；Huma 接受 `with_media`，API 0.21.0。Go unit/race、四服务 race、进程集成和本地只读 OCI 均通过。Client 展示尚未实施，故不认领完整 `PRIVACY-ACC-006`；远端 CI 与真实用户发布未验。

### PRIVACY-ACC-007 分层删除和防复活

- 覆盖需求：`PRIVACY-REQ-006`、`PRIVACY-REQ-008`。
- 前置条件：媒体血缘覆盖本地、API、队列、对象、Provider、缓存和备份。
- 操作步骤：删除单照片、单衣物图、单结果、全部 OOTD 数据和账号，注入部分失败、迟到回调和备份恢复。
- 期望结果：读权及时撤销；派生链按承诺清理；部分失败显示正确状态；备份到期或恢复后不复活已删除数据。
- 边界情况：删除某张图片保留结构化历史且无图降级，不保留已删除图片快照；无权用“已提交”代替“已删除”。
- 验收证据：删除 manifest、各存储查询、Provider 回执、备份恢复演练和 UI 录屏。
- 结果：`partial（本地合成数据后端）`。既有 19-06 账号删除受理时关闭会话/公开读取，Kafka 媒体删除完成后物理删除账号。18-04 的真实 PostgreSQL 验证无媒体即时完成、有媒体待清理、剩余媒体数、本次重试与既往单删隔离、错凭据/裸 ID 拒绝、7 天过期、撤销、pending 内部记录保留与完成后清除；实际进程验证注销后 Bearer 查询与撤销，无会话循环。Provider、缓存、生产备份恢复和 App/Web 状态仍待验。

### PRIVACY-ACC-008 取消、撤回和删除状态真实性

- 覆盖需求：`PRIVACY-REQ-007`。
- 前置条件：云任务处于排队、Provider 运行中和结果已返回窗口。
- 操作步骤：依次取消任务、撤回后续同意并请求删除，然后断网/重启。
- 期望结果：三种操作的影响范围和时间语义分离；Provider 无法即时停止、备份等待到期和删除重试均如实表达。
- 边界情况：App 重启后不回退到较乐观的状态，不因取消就声称已完成供应商删除。
- 验收证据：状态机/竞态测试、重启录屏和 Provider 回执。
- 结果：`pending`

### PRIVACY-ACC-011 Look 图片、模型与主动输出

- 覆盖需求：`PRIVACY-REQ-004`、`PRIVACY-REQ-006`、`AVATAR-REQ-043`、`AVATAR-REQ-044`；与 AVATAR-ACC-031、CLOUD-ACC-012 联合验收。
- 前置条件：授权合成素材、两个隔离 owner、有效 Look 图片版本与可选 GLB；14-01 对应入口已实际实现。
- 操作步骤：仅同意图片生成并完成结果；拒绝/同意模型生成；同版本反复查看；主动保存到相册/系统分享；删除模型、源图片、Look 与账号，注入迟到结果和清理失败。
- 期望结果：图片同意不授权模型/视频；私人缓存不跨 owner；相册 Add Only 仅在主动写入时请求，拒绝后图片和系统分享仍可用；输出清除无关元数据，不带原始本人照片、GLB、公开链接或会话凭据。
- 删除判定：删模型可保留图片，删源图片清理派生模型；未完成 worker 的清理依据不能先被级联删除，迟到结果不复活。App 可控临时输出按完成/超时策略清理，已交给其他应用或相册的副本不能宣称远程撤回。
- 证据：网络与权限录屏、owner/用途/血缘查询、临时文件清单、故障注入、结果抓包；数据主体导出按 ACC-006 独立验收。
- 结果：`pending`；本次仅替换设计，未运行本场景。

## 证据与判定

证据必须包含唯一 ID、commit/build、市场/地域、设备/环境、夹具版本、步骤/命令、持久 artifact 地址、时间、执行/复核人、结果和限制。证据自身不得含真实用户敏感数据。

本地核心发布必须通过其适用的隐私场景。云端、导出或动态能力未开启时，其条件场景可保持 `pending/blocked`，但对应入口、网络和生产开关必须确认关闭。
